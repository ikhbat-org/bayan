# BYN1013: conditional expression in a collection literal

**Why.** Inside `[ … ]`, a bare `c ? a : b` is easy to misread as several elements. Bayan asks for parentheses so element boundaries stay obvious.

**Example.**

```
let xs = [1, ready ? 2 : 3]
```

**Fix.** Parenthesize it: `[1, (ready ? 2 : 3)]`. The diagnostic carries this fix.

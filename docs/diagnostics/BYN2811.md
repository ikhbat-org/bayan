# BYN2811: `extension` conformance

**What.** An `extension T : I` declaration adds a conformance to a type after the type is declared.

**Why.** Retroactive conformance is not supported yet. A type's conformances are listed on its own declaration, so they are all in one place and a conformance cannot appear or disappear depending on which module is imported.

**Example.**

```
struct Money {
    i64 cents
}

extension Money : IShape {
    i64 area() => 0
}
```

**Fix.** List the interface on the type's declaration and move the members into it:

```
struct Money : IShape {
    i64 cents;

    i64 area() => 0;
}
```

If the type is not yours to change, wrap it in a struct that conforms.

# BYN3003: returning a borrow of local storage

**Why.** A function's locals, by-value parameters and `stackalloc` buffers are freed when it returns, so a span or string pointing into them would dangle. A returned borrow may only point into what the caller passed in (spec §9.4 rule 4).

**Example.**

```
Span<i64> scratch() {
    let buf = stackalloc i64[4]
    return buf[1..]
}
```

**Fix.** Let the caller pass the buffer (a `Span<T>` parameter) or an allocator in, and borrow or allocate from that.

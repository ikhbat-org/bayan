# BYN2410: non-exhaustive switch

**Why.** A `switch` expression must produce a value for every input, and a `switch` over an enum, an error enum or `bool` must name every case so adding a variant shows every place that needs updating.

**Example.**

```
let ok = true
let n = ok switch { true => 1 }
```

**Fix.** Add the missing cases (listed in the label), or `_ => …` / `default:` for the rest. For a union declared in this package, the help names the missing arms and does not suggest `_`, since a `_` arm on such a union is the BYN2712 warning.

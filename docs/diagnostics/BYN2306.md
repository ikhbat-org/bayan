# BYN2306: argument modifier mismatch

**Why.** `ref` and `out` show at the call site that the callee may change the caller's variable; they must match the parameter.

**Example.**

```
void bump(ref i64 total) { }
var total: i64 = 0
bump(total)   // void bump(ref i64 total)
```

**Fix.** Write the modifier the parameter declares: `bump(ref total)`.

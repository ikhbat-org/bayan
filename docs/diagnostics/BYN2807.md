# BYN2807: type argument does not conform

**What.** A call or a type names a type argument that does not meet its parameter's `where` constraint. The error is reported where the type is chosen: at the call, or at a generic's own call when it passes one of its type parameters along.

**Why.** The generic code was checked against its constraints, so it may call any member they declare. A type that does not conform has no such member to call. Only structs conform to interfaces, and a type parameter conforms only to the interfaces in its own `where` clause.

**Example.**

```
interface IShape {
    i64 area()
}
struct Square {
    i64 side
}
i64 measure<T>(ref T shape) where T : IShape => shape.area()
void main() {
    var s = Square { side: 2 }
    print($"{measure(ref s)}")
}
```

**Fix.** Conform the type to the interface, or pass one that does. For a type parameter, add the interface to its `where` clause:

```
struct Square : IShape {
    i64 side

    i64 area() => side * side
}
```

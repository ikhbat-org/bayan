# BYN2740: cannot infer a type argument

**Why.** A call of a generic function reads its type arguments from the types of its arguments. When no argument mentions a type parameter (or every such argument is `null`), there is nothing to read it from; Bayan does not infer type arguments from the expected type of the call.

**Example.**

```
T? none<T>() => null
var x = none()
```

**Fix.** Write the type arguments out, as in `none<i64>()`, or pass an argument the type can be read from.

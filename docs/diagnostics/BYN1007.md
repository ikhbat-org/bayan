# BYN1007: `unless` with a negated condition

**Why.** `unless (!x)` is a double negative and means `if (x)`. Bayan rejects it so conditions read directly. From design round 3 the same holds for the word spelling `not`, in both the block and the postfix form; BYN1007 covers both spellings (it absorbed the retired [BYN1049](BYN1049.md)).

**Example.**

```
unless !done { step() }
return 0 unless !ok
return 0 unless not ok
```

**Fix.** Use `if` with the condition un-negated (`return 0 if ok`). The diagnostic carries the rewrite.

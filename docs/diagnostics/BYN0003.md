# BYN0003: unterminated string literal

**Why.** A regular string must close on the line it opens. A raw `"""` string must close before the end of the file. An interpolated string's `{` must be closed before the string ends.

**Example.**

```
let a = "open
```

**Fix.** Add the closing `"`. For text spanning lines use a raw string:

```
let a = """
    several
    lines
    """
```

# BYN0011: unit suffix on a hex or binary literal

**Why.** Unit suffixes such as `dec` or `s` attach meaning to a decimal quantity. Hex and binary literals are bit patterns, so only the built-in width suffixes `u`, `l`, `ul` are allowed on them.

**Example.**

```
let a = 0xFFs
```

**Fix.** Write the value in decimal (`255s`), or drop the suffix.

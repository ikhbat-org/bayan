# BYN2813: `ref this` member through `dyn ref readonly`

**What.** A member that takes `ref this` is called through a `dyn ref readonly` value. This includes default methods declared `ref this`.

**Why.** `ref this` means the call may modify the value. A `dyn ref readonly` borrow promises that the value is not modified through it.

**Example.**

```
interface ICounter {
    i64 next(ref this)
}

void show(dyn ref readonly ICounter c) {
    print($"{c.next()}")
}
```

**Fix.** Take a writable `dyn ref`:

```
void show(dyn ref ICounter c) {
    print($"{c.next()}");
}
```

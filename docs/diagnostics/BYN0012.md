# BYN0012: reserved word used as identifier

**Why.** Every keyword is reserved, including those kept for future features (`actor`, `macro`, `select`, `become`), so adding a feature later cannot break existing code. The C# primitive type names (`sbyte`, `byte`, `short`, `ushort`, `int`, `uint`, `long`, `ulong`, `nint`, `nuint`, `float`, `double`) are reserved too: they name the sized types in every project, so none can be declared as a name (`i32 int`, `let long = 4`).

**Example.**

```
let actor = 1
```

**Fix.** Choose another name, e.g. `actorId`.

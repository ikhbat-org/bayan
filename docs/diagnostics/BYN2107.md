# BYN2107: getter modifies its value

**Why.** Reading a property must not change the value; otherwise `x.count` in a `let` would be an error at a distance.

**Example.**

```
struct Counter {
    i64 n
    i64 next => record()
    i64 record(ref this) {
        n += 1
        return n
    }
}
```

**Fix.** Make it a method: `i64 next() { … }`.

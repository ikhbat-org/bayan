# BYN2770: unknown attribute

**Why.** Attributes change how a declaration compiles, so a misspelled or unsupported one is an error instead of being ignored. The attributes are `[ExitCode(n)]`, on an error variant, and `[Cases(...)]`, on a test that takes parameters.

**Example.**

```
@inlin
void step() { }
```

**Fix.** Remove the attribute, or correct its name.

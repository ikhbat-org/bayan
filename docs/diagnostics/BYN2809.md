# BYN2809: `dyn I` by value is not supported yet

**What.** A type is written `dyn I` without `ref`.

**Why.** An owned dynamic value would need its size at run time and an allocation to hold it. Only the borrowed form `dyn ref I` is supported: it points at a value that lives elsewhere and never allocates (spec 006, non-goals).

**Example.**

```
interface IShape {
    f32 area()
}

void show(dyn IShape s) { }
```

**Fix.** Borrow the value with `dyn ref` (or `dyn ref readonly` when only members without `ref this` are called):

```
void show(dyn ref IShape s) { }
```

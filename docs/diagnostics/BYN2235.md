# BYN2235: spread of something that is not a sequence

**What.** `..x` inside a collection literal adds every element of `x`, so `x` must be a `List<T>`, a `Span<T>` or a fixed array `T[N]`. A number, a string or a map has no elements to add this way.

**Why.** A spread copies a sequence's elements into the literal in order; anything else has no order or no elements of the literal's element type.

**Example.**

```
let n = 5
let xs: List<i32> = [..n, 1]
```

**Fix.** To add one value, drop the `..`; to add several, spread a list, span or fixed array.

```
let n = 5
let xs: List<i32> = [n, 1]
```

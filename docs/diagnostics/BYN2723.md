# BYN2723: enum argument is not constant

**Why.** The data of an enum member is stored once in a static table, indexed by ordinal, so every argument must be known at compile time: a literal, a `const`, an expression of those, or a member of a plain enum.

**Example.**

```
i64 twice(i64 n) => n * 2
enum Size(i64 bytes) {
    small(1)
    large(twice(512))
}
```

**Fix.** Write the value as a literal or a `const` (`large(1024)`), or compute it at run time from the member, for example in a function taking the enum.

# BYN2806: member not found in the constraints

**What.** Generic code uses a member on a type parameter, and no interface in the parameter's `where` clause declares it. Inside a default method, `this` stands for the interface's `Self`, whose only constraint is that interface.

**Why.** Generic code is checked once, at its definition, not separately for each type it is called with. It can rely only on what its constraints promise. Otherwise a call with a new type could break code that has no error of its own.

**Example.**

```
interface IShape {
    i64 area()
}

void show<T>(ref T shape) where T : IShape {
    print($"{shape.perimeter()}")
}
```

**Fix.** Declare the member in a constraining interface, or add an interface that declares it to the `where` clause:

```
interface IShape {
    i64 area();
    i64 perimeter();
}

void show<T>(ref T shape) where T : IShape {
    print($"{shape.perimeter()}");
}
```

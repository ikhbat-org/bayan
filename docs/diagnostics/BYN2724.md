# BYN2724: invalid enum parameter

**Why.** Each parameter of a data enum becomes a static table with one entry per member, so its type must have a static form: a number type, `bool`, `rune`, `string` or a plain enum (one without data). Parameters are read-only values, so `ref`, `out`, `in`, `move` and default values are not allowed either.

**Example.**

```
struct Point { i64 x }
enum Shape(Point corner) {
    square(Point { x: 0 })
}
```

**Fix.** Store the parts as separate scalar parameters (`enum Shape(i64 cornerX)`), and pass every argument explicitly.

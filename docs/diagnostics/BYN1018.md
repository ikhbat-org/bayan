# BYN1018: body needs braces

**What.** A single statement as the body of `if`, `else`, `unless`, `while`, `for` or `do`, or a declaration as the body of `defer` (`defer stmt;` is otherwise legal, spec §7.6; `defer let x = 1;` declares a local nothing can see).

**Why.** A braceless body invites the classic bug where a second indented line looks guarded but is not. Every body is a block.

**Example.**

```
if (done) return
```

**Fix.** Wrap the statement in `{ }` (the machine fix does this):

```
if done { return; }
```

When the header has its own fix (BYN1017, BYN1007, BYN1019, …), that fix also adds the braces, so it is valid applied alone.

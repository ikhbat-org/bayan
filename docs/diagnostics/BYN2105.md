# BYN2105: readonly field

**Why.** A `readonly` field keeps the value it is given in a constructor or struct literal.

**Example.**

```
struct Id { readonly i64 value }
let id = Id { value: 1 }
id.value = 2
```

**Fix.** Create a new value (`id with { value: 2 }`), or drop `readonly` from the field.

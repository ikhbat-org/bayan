# BYN2745: generic type needs itself with a larger type argument, without end

**Why.** Instantiating a generic struct or union declares its members, and a member whose type is the same template at a larger type argument needs that instance first. When each instance needs a larger one (`G<Owned<T>>` needs `G<Owned<Owned<T>>>`, which needs `G<Owned<Owned<Owned<T>>>>`, and so on), there is no end to them. The checker stops after 64 nested instances and reports the template, naming the first instance and the larger one it needs. Unlike [BYN2761](BYN2761.md), `Owned<…>` or `List<…>` around the member does not help: the instances are needed whatever holds them.

**Example.**

```
struct G<T> {
    List<G<Owned<T>>> g
}
let x = G<i64> {}
```

**Fix.** Give the member the same type arguments as the type it is in (`List<G<T>> g`), or a type that does not name the template.

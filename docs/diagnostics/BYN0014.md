# BYN0014: single `}` in an interpolated string

**Why.** In `$"…"` strings `{` opens an expression and `}` closes it. A lone `}` in the text is ambiguous, so literal braces are written doubled.

**Example.**

```
let s = $"stray } here"
```

**Fix.** Write `}}` (and `{{` for a literal `{`). The diagnostic carries this fix.

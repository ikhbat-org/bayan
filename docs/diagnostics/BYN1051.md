# BYN1051: `except` is not allowed in a `case` pattern

**Why.** `except` removes cases from a value ([grammar guide](../bayan-grammar.md)); it is an expression, not part of a pattern. A `case` label or a `switch` arm takes a pattern, and `not` already says "anything but this".

**Example.**

```
Shape pick(Shape s) {
    switch s {
        case _ except .circle: return s
        default: return s
    }
}
```

**Fix.** Write `not` before the pattern:

```
        not .circle => return s
```

`_ except p` carries a machine-applicable fix, and `bayan format` applies it. Any other left side has no fix: the parser reads it as `left and not p`.

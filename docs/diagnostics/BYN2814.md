# BYN2814: `ref this` does not match the interface

**What.** A struct's member and the interface member it provides disagree on `ref this`: one takes it and the other does not.

**Why.** `ref this` decides whether a call may modify the value it is called on. Callers through the interface rely on the interface's choice: a read-only member must not change the value, and a `ref this` member needs a mutable one.

**Example.**

```
interface ICounter {
    i64 next(ref this)
    i64 peek()
}

struct Counter : ICounter {
    i64 value

    i64 next() => value

    i64 peek(ref this) => value
}
```

**Fix.** Add or remove `ref this` to match the interface:

```
struct Counter : ICounter {
    i64 value

    i64 next(ref this) {
        value += 1
        return value
    }

    i64 peek() => value
}
```

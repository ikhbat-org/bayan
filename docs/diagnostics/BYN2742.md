# BYN2742: wrong number of type arguments in a call

**Why.** A generic function takes exactly as many type arguments as it declares type parameters; a function that is not generic takes none.

**Example.**

```
T pick<T>(bool first, T a, T b) => first ? a : b
var x = pick<i64, string>(first: true, a: 1, b: 2)
```

**Fix.** Pass one type argument per type parameter, or leave them all out and let the arguments decide.

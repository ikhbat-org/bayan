# BYN1008: postfix condition on a compound statement

**Why.** A postfix `if` or `unless` (`return x if c;`) is meant for one short simple statement: a return, break, continue, assignment or call. On a block, loop or declaration it hides control flow at the end of a long construct, and on a declaration it would leave the name unassigned.

**Example.**

```
let y = 2 if ready
```

**Fix.** Use a prefix `if ready { … }`, or declare the variable first and assign it conditionally.

# BYN0013: escape is not a Unicode scalar value

**Why.** `\u{…}` must name a Unicode scalar: U+0000–U+D7FF or U+E000–U+10FFFF. Surrogates and values above U+10FFFF cannot be encoded in UTF-8.

**Example.**

```
let c = '\u{D800}'
```

**Fix.** Use the scalar value you meant. For characters outside the BMP write the code point directly (`\u{1F600}`), not a surrogate pair.

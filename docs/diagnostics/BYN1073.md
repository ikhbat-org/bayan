# BYN1073: lambda that can use `it`

A style lint (`lambdas.it`): reported by `bayan check` only, never by `build`, `run` or `test`. Its severity comes from `lints` in `package.byn` (`.suggestion` by default; `.none` silences it, `.error` makes `bayan check` fail).

**What.** A lambda passed as an argument, with one parameter, whose body only reads a member of that parameter (`c => c.name`).

**Why.** `it` is the implicit parameter of a lambda argument (spec §3.16); naming a parameter that is used once only adds a word.

**Example.**

```
let names = customers.map(c => c.name)
```

**Fix.** Write `it` and drop the parameter (the machine fix does it):

```
let names = customers.map(it.name)
```

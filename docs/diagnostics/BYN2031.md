# BYN2031: `toString()` call

**What.** A call to `toString()` or `ToString()`. Bayan has no such method.

**Why.** Display has one protocol (SPEC §6.6): a type writes itself with `formatInto(ref StrBuf)`, and the allocating `format()` is derived from it. Interpolation calls `formatInto` directly, so `$"{x}"` never builds a temporary string. A `toString()` beside them would be a second, allocating way to do the same thing.

**Example.**

```
let total = 1
let text = total.toString()
```

**Fix.** Call `format()` (the machine fix renames the call), or interpolate the value where it is written:

```
let text = total.format()
print($"{total}")
```

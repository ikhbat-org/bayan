# BYN2710: union case with data has a value

**Why.** Only payload-free cases can declare an integer value; a case that carries data is not a plain integer on the C side.

**Example.**

```
union Shape {
    circle(f32 r) = 1
    none = 2
}
```

**Fix.** Remove the value from the case that carries data:

```
union Shape { circle(f32 r), none = 2 }
```

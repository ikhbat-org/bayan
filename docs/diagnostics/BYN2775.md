# BYN2775: `assert` needs a `bool`

**What.** The expression after `assert` is not a `bool`.

**Why.** `assert expr;` checks that `expr` is `true` and panics otherwise, showing the value of each sub-expression (spec §20). There is no truthiness in Bayan: a number, a string or an optional is not true or false by itself, so the comparison must be written out.

**Example.**

```
let items = List<i64>()
let count = items.length
assert count
```

**Fix.** Compare the value with what you expect:

```
let count = items.length
assert count == 3
```

For an optional, test it with `is not null`: `assert found is not null;`.

# BYN2771: invalid `main` signature

**Why.** The runtime calls `main` itself, so it accepts only the shapes it knows how to call: return `void` or `i32` (the exit code), take nothing or `ReadOnlySpan<string> args` (the command-line arguments without the program name), with or without `fails`.

**Example.**

```
string main(i64 count) { return "done" }
```

**Fix.** Use one of `void main()`, `i32 main()`, `void main(ReadOnlySpan<string> args)` or `i32 main(ReadOnlySpan<string> args)`, optionally followed by `fails E`.

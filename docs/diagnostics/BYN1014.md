# BYN1014: stacked case labels

**Why.** C-style `case a: case b:` relies on fall-through, which Bayan switch sections do not have. One label with an `or` pattern states the intent directly.

**Example.**

```
switch day {
    case .sat:
    case .sun:
        rest()
        break
}
```

**Fix.** Write `case .sat or .sun:`. The parser merges stacked labels this way to keep checking the rest of the file.

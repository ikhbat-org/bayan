# BYN2791: binding is mutated in the guard of `switch move …`

**Why.** In `switch move x` each pattern binding owns the part it binds, but only once its arm is selected. A `when` guard runs before that: when it fails, the value goes back to the switch and a later arm binds the same storage. A guard that changed the binding (grew a list, took a field, passed it by `ref` or `out`, moved it) would leave that later arm with a stale or freed copy. So inside the guard the arm's bindings and their parts are read-only.

**Example.**

```
struct Bag {
    List<i64> items

    public i64 grow(ref this) uses alloc {
        this.items.append(1)
        return this.items.length
    }
}
union Slot {
    full(Bag b)
    empty
}
bool bump(ref List<i64> xs) {
    xs.append(7)
    return true
}
bool keep(move Bag b) => true
void consume(move Bag b) { }
void inspect(move Slot s) {
    switch move s {
        case .full(var x) when x.grow() > 50: print("big")
        case .full(var x) when bump(ref x.items): print("bumped")
        case .full(let x) when keep(move x): print("kept")
        case .full(var y):
            y.grow()
            consume(move y)
        default:
    }
}
```

**Fix.** Read the binding in the guard and change it in the arm's body: `case .full(var x) when x.items.length > 49: x.grow(); …`. Without `move`, bindings borrow and this rule does not apply.

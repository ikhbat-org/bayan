# BYN3001: borrowed value in a struct field

**Why.** A `string`, `Span<T>` or `StrBuf` points into memory owned elsewhere. Storing it in a struct would let the struct outlive that memory; v0.1 has no way to check that, so it is not allowed.

**Example.**

```
struct Window { Span<u8> bytes }
```

**Fix.** Storing borrows in structs arrives in a later version; copy the data instead (for example into a `List<u8>`), or store an index.

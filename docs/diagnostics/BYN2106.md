# BYN2106: modifying a temporary or read-only value

**Why.** Only variables, fields of variables, and elements of lists, arrays and spans can be written. A call result is a temporary copy, and the bytes of a string are read-only.

**Example.**

```
let s = "abc"
s.bytes[0] = 65
```

**Fix.** Store the value in a `var` first, or copy the bytes into a buffer you own.

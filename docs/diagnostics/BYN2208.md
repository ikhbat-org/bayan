# BYN2208: bad binary operands

**Why.** Arithmetic needs two numbers of compatible types; mixing signed and unsigned, or numbers and `bool`, needs an explicit cast so the intended type is visible.

**Example.**

```
let a: i64 = 1
let b: u64 = 2
let c = a + b
```

**Fix.** Cast one operand so both have the same type.

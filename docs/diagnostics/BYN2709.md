# BYN2709: union case value is not an integer constant

**Why.** A payload-free case may declare the integer it is stored as, for C interop: `union Mode { read = 1, write = 2 }`. The value becomes the case's tag, an `i32`, so it must be an integer literal (optionally negated) that fits in `i32`.

**Example.**

```
union Mode {
    read = 1.5
    write = "w"
}
```

**Fix.** Write the value as an integer literal, or remove it:

```
union Mode { read = 1, write = 2 }
```

# BYN5008: not a particle

**Why.** A parameter may start with a particle that names its role: `from`, `to`, `until`, `through`, `at`, `by`, `for` or `as`. Any other word in that position, followed by a passing mode or a type and a name, is not one.

**Message.** `{0}` is not a particle

**Help.** choose one of `from`, `to`, `until`, `through`, `at`, `by`, `for`, `as`

**Example.**

```
void copy(over Buf src, to Buf dst) {
    return
}
```

**Fix.** Choose one of the eight particles, or remove the word:

```
void copy(from Buf src, to Buf dst) {
    return
}
```

The diagnostic has no machine-applicable fix.

See GRAMMAR: Role marks (docs/bayan-grammar.md §15).

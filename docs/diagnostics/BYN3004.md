# BYN3004: modified while borrowed

**Why.** Adding to or clearing a `List` can move its elements, clearing a `StrBuf` overwrites its text, and resetting an `Arena` frees everything allocated from it. A span, string or loop that still points into the old storage would read freed or changed memory (spec §9.4 rules 5 and 6).

**Example.**

```
var xs = List<i64>()
xs.append(1)
let view = xs.span
xs.append(2)
print($"{view[0]}")
```

**Fix.** Finish using the borrow before the change, or copy what it needs first. To grow a list you are iterating over, collect the new items in another list and add them after the loop.

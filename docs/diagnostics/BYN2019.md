# BYN2019: not a value

**Why.** Types and modules name things at compile time; they cannot be stored or passed. Neither can a function or method named without its call parentheses: there are no function values yet.

**Example.**

```
struct Money { i64 cents }
let t = Money
```

**Fix.** Construct a value (`Money { cents: 0 }`) or call a function from the module (`money.parse(s)`). For a method, add the parentheses: `items.copy()`.

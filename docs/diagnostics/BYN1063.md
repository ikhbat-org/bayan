# BYN1063: `requires` on a function

**Why.** A function's precondition is written `expects condition`; `requires` belongs to field and type rules. `requires` on a function is an input form.

**Example.**

```
i64 half(i64 n) requires n >= 0 { return n / 2 }
```

**Fix.** Write `expects`: `i64 half(i64 n) expects n >= 0 { … }`. The diagnostic carries a machine-applicable fix, and `bayan format` applies it.

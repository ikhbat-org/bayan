# BYN1010: `goto` is not supported

**Why.** Bayan has no `goto`. Structured exits cover its legitimate uses: labeled `break` and `continue` leave nested loops, and `defer` handles cleanup. `goto case` is not supported either; switch sections never fall through.

**Example.**

```
goto done
```

**Fix.** Label the loop and use `break label;` or `continue label;`. For shared switch code, move it into a function.

# BYN2800: interface name must start with `I`

**What.** An `interface` is named without the `I` prefix, or the `I` is not followed by an uppercase letter.

**Why.** An interface is not a type on its own: it is listed after `:`, named in a `where` bound or used as `dyn ref I`. The `I` prefix tells the reader which names are interfaces at every one of those places (spec §5.1).

**Example.**

```
interface Shape {
    f32 area()
}
```

**Fix.** Rename it to `I` followed by the PascalCase name (the machine fix does):

```
interface IShape {
    f32 area();
}
```

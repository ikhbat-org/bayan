# BYN2615: panic handler reads a local moved after it

**What.** A `defer panicking` body reads a local that is moved, on some path, after the handler is registered.

**Why.** A panic handler runs at a panic anywhere in its scope, not only at the scope's exit. A panic after the move would run the handler on a value that has already been handed away and may be freed (spec §7.6).

**Example.**

```
void sink(move List<i64> xs) { }
let ys = List<i64>()
defer panicking print($"handler sees {ys.length}")
sink(move ys)
```

**Fix.** Move the value before registering the handler, or read a `let` copied from it there:

```
let ys = List<i64>();
let n = ys.length;
defer panicking print($"handler sees {n}");
sink(move ys);
```

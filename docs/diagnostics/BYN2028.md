# BYN2028: `let` shadows a local of the same type

**What.** A `let` redeclares a local in the same scope, and the new value has the same type as the old one (warning).

**Why.** Redeclaring a name with `let` is for changing its type as a value moves through steps: `let count = count.length;` turns a `string` into an `i32`. When the type stays the same, the second `let` hides the first value without saying how it differs, and a reader cannot tell which one a later line means (HANDOFF §4).

**Example.**

```
i64 readSize() => 1
let size = readSize()
let size = size * 2
```

**Fix.** Reuse the first one, or name the second one for what it is:

```
let size = readSize();
let doubled = size * 2;
```

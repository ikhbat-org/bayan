# BYN1025: `catch (e)` binding

**What.** A `(name)` binding after `catch`.

**Why.** A handler that needs the error matches it: each `catch switch` arm binds the error at the type it matched, so the binding always has a precise type.

**Example.**

```
let n = parse(s) catch (e) switch {
    .empty => 0,
    _ => fallback(e),
}
```

**Fix.** Remove `(e)` (the machine fix does this when `switch` follows) and bind the error in the arms that need it:

```
let n = parse(s) catch switch {
    .empty => 0,
    ParseError e => fallback(e),
}
```

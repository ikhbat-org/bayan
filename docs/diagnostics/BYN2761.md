# BYN2761: type contains itself by value

**Why.** Structs and unions are stored inline: a field or payload of type `T` holds a whole `T`. A type that contains itself by value, directly or through other structs, unions, optionals, arrays or tuples, would be infinitely large. The message lists the cycle, starting and ending at the reported type. `Owned<T>` is a pointer into an allocator and `List<T>` holds its elements elsewhere, so either breaks the cycle.

**Example.**

```
union Expr {
    lit(i64 v)
    add(Expr l, Expr r)
}

struct Tree {
    i64 value
    Forest children
}
struct Forest { Tree first }
```

**Fix.** Refer to the inner value through `Owned<…>`, built with `Owned(value)` from `context.allocator`:

```
union Expr {
    lit(i64 v),
    add(Owned<Expr> l, Owned<Expr> r),
}
```

or keep the children in a `List<…>`, or refer to them by index.

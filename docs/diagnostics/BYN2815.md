# BYN2815: only structs can conform

**What.** A union or an enum lists interfaces after `:`.

**Why.** Conformance is for structs only for now. Union and enum members are not in the language yet, so a union or enum has nowhere to provide an interface's members (spec 006, handoff Q100).

**Example.**

```
union Shape : IShape {
    circle(i64 r)
    none
}
```

**Fix.** Wrap the union or enum in a struct that conforms, and switch on it inside the members:

```
union Shape {
    circle(i64 r),
    none,
}

struct AnyShape : IShape {
    Shape shape;

    i64 area() => shape switch {
        .circle(let r) => 3 * r * r,
        .none => 0,
    };
}
```

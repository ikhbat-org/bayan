# BYN2783: a borrowed binding cannot be changed or moved

**Why.** A `for` loop variable and a `switch` or `is` pattern binding of a unique type borrow from the value they were bound to: they name storage that the list, union or other subject still owns. This holds for `var` bindings too. Changing the binding (a mutating member call, an assignment to it or to its fields) or moving it would change or take storage behind the owner's back.

**Example.**

```
var lists = List<List<i64>>()
lists.append(List<i64>())
for xs in lists { xs.append(1) }
```

**Fix.** Change the element through its owner:

```
for i in 0..lists.length { lists[i].append(1) }
```

or copy the binding into a local of its own with `xs.copy(to: alloc)`.

# BYN7005: literal of a struct with states names no state

**Message.** `{0}` has states; a literal must name one: `{0}.{1} { … }`

**Help.** name the state the value starts in

**Why.** A struct with states is built as `T.state { fields…, payload… }`. No state is a safe default, so a plain `T { … }` or `T()` does not say which state the value starts in.

**Example.**

```
struct Order {
    i64 id
    states {
        draft
        paid(i64 payment)
    }
}
let order = Order { id: 1 }
```

**Fix.** Name the state: `let order = Order.draft { id: 1 }`.

# BYN2712: `_` arm on a union declared in this package (warning)

**Why.** A `switch` on a union is exhaustive: when a case is added, every `switch` that does not handle it is an error, which points at the code to update. A `_` arm matches every case, including the ones added later, so it hides those errors. For a union declared in the same package, you can list its cases instead.

**Example.**

```
union Shape {
    circle(f32 r)
    rect(f32 w, f32 h)
    none
}

f32 area(Shape s) => s switch {
    .circle(let r) => r * r,
    _ => 0,
}
```

**Fix.** List the remaining cases instead of `_` (the help lists them):

```
f32 area(Shape s) => s switch {
    .circle(let r) => r * r,
    .rect(_, _) or .none => 0,
}
```

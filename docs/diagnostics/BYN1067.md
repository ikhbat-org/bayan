# BYN1067: pointer type outside `extern`

**Why.** Pointers exist only to call C. A pointer type may appear only in an `extern` declaration; everywhere else, use a reference (`ref`), a span or an index.

**Example.**

```
void fill(u8* buffer) { }
```

**Fix.** Pass a `ref` or a span, or wrap the C call in an `extern` declaration. There is no automatic fix.

# BYN2026: declaration as a statement body

**No longer reported.** Retired in design round 2: a statement body is always a block, so a braceless body is BYN1018 before binding, and a declaration can no longer be the whole body. The code stays reserved.

**Why (before round 2).** `if (c) let x = 1;` declares a local that no code can see.

**Example.**

```
if (ready) let x = 1
```

**Fix.** Use a block: `if ready { let x = 1; … }`, or declare the local before the `if`.

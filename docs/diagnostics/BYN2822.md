# BYN2822: function type not supported here

**Why.** A function value borrows the frame that made it, so in 007 it lives only where that frame outlives it: a parameter, a local, or the target of a `type` alias naming one of those. A struct field, a return type, a type argument, or the element of an optional, span, list, map, array or tuple would carry it out of that frame.

**Example.**

```
struct Line {
    i32 qty
}
struct Money {
    i64 cents
}
type Pricer = Line -> Money uses net
struct Shop {
    Pricer pricer
}
```

**Fix.** Take the function as a parameter of the function that calls it: `Money total(Line line, Pricer pricer)`.

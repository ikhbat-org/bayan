# BYN1031: `T!E` return type

**What.** A function declared `T!E name(…)` or `T!(A, B) name(…)`.

**Why.** What a function can fail with is written once, after the parameters, with `fails`.

**Example.**

```
i64!ParseError parse(string s) { return 0 }
```

**Fix.** Move the errors to a `fails` clause (the machine fix does this):

```
i64 parse(string s) fails ParseError { … }
```

# BYN2116: operator with `ref this`

**Not reported yet.** Operator declarations are spec-only (spec §2); the code is reserved for when they arrive.

**What.** An operator (`+ - * / %`, unary `-`, `[]` or `compare`) declares `ref this`.

**Why.** Operators are `static` and build a result from their operands; `a + b` must not change `a`. A mutating form such as `+=` is derived from the operator, not written by hand.

**Example.**

```
struct Version {
    i64 major
    i64 minor

    static Ordering compare(ref this, Version other) { }
}
```

**Fix.** Take both operands as parameters:

```
struct Version {
    i64 major;
    i64 minor;

    static Ordering compare(Version a, Version b) { … }
}
```

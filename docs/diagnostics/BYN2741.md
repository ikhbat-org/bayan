# BYN2741: conflicting type arguments

**Why.** Every argument whose parameter mentions a type parameter fixes that type parameter. When two of them fix it to different types and neither converts to the other, the call has no single instantiation.

**Example.**

```
T pick<T>(bool first, T a, T b) => first ? a : b
var x = pick(first: true, a: 1, b: "one")
```

**Fix.** Make the arguments agree, convert one of them, or write the type arguments out, as in `pick<string>(…)`.

# BYN2788: `take()` needs a `List`, `Map`, `StrBuf` or an optional of a unique type

**Why.** `x.take()` moves the value out of a place and leaves that type's empty value behind, so the place stays usable. Only types with an obvious empty value support it: an empty `List`, `Map` or `StrBuf`, and `null` for an optional holding a unique type. Other types have no empty value to leave, and a plain value needs no `take()` because it is copied.

**Example.**

```
var count = 3
let n = count.take()
```

**Fix.** Copy a plain value, `let n = count;`. For a unique struct, move the whole local with `move x`, or `take()` the collection fields inside it.

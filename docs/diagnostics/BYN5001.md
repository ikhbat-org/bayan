# BYN5001: `-ed` member that takes `ref this`

**What.** A member is named with the `-ed` form of a verb (`sorted`, `trimmed`, `joined`) but takes `ref this`, so it changes `this`.

**Why.** The `-ed` name is reserved (spec §5.2, [grammar guide](../bayan-grammar.md) tree 1 and 2): it names a changed copy or a view of `this` and never changes it. A member that acts on `this` is a plain verb on `ref this` (`sort`, `trim`). The `-ed` form does not need a plain verb to exist: an immutable type such as `string` has `trimmed()` with no `trim`.

**Message.** `{0}` changes `this`; name it `{1}`

**Help.** name the member that changes `this` with the plain verb, and keep `-ed` for the copy or view

**What counts as `-ed`.** One lowercase word of five letters or more ending in `-ed`, on a member that takes `ref this` and does not return `bool`. The plain verb offered in the message is found by dropping `-ed` (`sorted` → `sort`), dropping only the `d` (`reversed` → `reverse`), undoing a doubled consonant (`trimmed` → `trim`) or `-ied` (`copied` → `copy`). Not participles: words ending in `-eed` (`need`, `speed`, `seed`), shorter words (`red`, `bed`, `used`), and `hundred`, `embed`, `shred`, `naked`, `wicked`, `sacred`, `kindred`. An irregular form declared in `forms` in the project dictionary counts too (`forms: ["regrind": "reground"]`; see [BYN5014](BYN5014.md)). Not checked: math vocabulary (`sqrt`, `radians`, …), and typestate states (`states { paid, shipped }`), which are not members. A `bool` member named `closed` is a state: see [BYN5102](BYN5102.md).

**Example.**

```
struct Words {
    string text
    void sorted(ref this) { }
}
```

**Fix.** Name the member that changes `this` with the plain verb, and keep `-ed` for the copy or the view:

```
struct Words {
    string text

    void sort(ref this) { … }
}
```

**Where this comes from.** The `-ed` copy follows the Arabic passive participle (mafʿūl), which names the result of an act, not the act. See the [grammar guide](../bayan-grammar.md) §12.

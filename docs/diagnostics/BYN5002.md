# BYN5002: state member modifies `this`

**What.** A member with no arguments named `isX`, `hasX` or `canX` is declared `ref this`.

**Why.** `is`, `has` and `can` name a state (spec §5.2, [grammar guide](../bayan-grammar.md) tree 3): a reader expects `if q.isEmpty` to look, not to change `q`, and a state member is callable on a `let`. A member that changes `this` is an action, named with a verb on `ref this` (tree 1). A member with arguments (`hasRoomFor(n)`) is not checked.

**Example.**

```
struct Queue {
    i64 count

    bool isEmpty(ref this) {
        count = 0
        return true
    }
}
```

**Fix.** Remove `ref this` so the member only reads:

```
struct Queue {
    i64 count

    bool isEmpty() => count == 0
}
```

If it must change `this`, name the action with a verb: `bool drain(ref this)`.

**Where this comes from.** The `is` / `has` / `can` state follows the Arabic attribute (ṣifa), which describes a thing without acting on it. See the [grammar guide](../bayan-grammar.md) §12.

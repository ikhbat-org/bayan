# BYN2784: a collection holding a unique value cannot be copied

**Why.** `copy(to:)` on a `List` or `Map` copies the elements, keys and values as they are. When those are themselves a `List`, `Map`, `StrBuf` or `Owned` (or a struct, union, tuple, array or optional holding one), the copy would share their storage with the original, and growing one would free memory the other still points to.

**Example.**

```
var lists = List<List<i64>>()
let copy = lists.copy(to: arena)
```

**Fix.** Build the copy with a loop that copies each element:

```
var copy = List<List<i64>>()
for inner in lists { copy.append(inner.copy(to: arena)) }
```

or share the original by `ref`.

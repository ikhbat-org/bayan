# BYN5104: a name that does not agree in number

A lint: it never blocks a build. It checks the public API only: a `public` field or property of a `public` struct, and a parameter of its `public` methods; a name the module keeps to itself is not checked (grammar guide §1, checker scope). A name under a rename attribute (`@json(name: …)`, `@column(…)`) is forced from outside and not checked.

**What.** Two messages, one rule: a collection is named with a plural or a collective, anything else with a singular (grammar guide §14).

- "`{0}` holds a collection; name it with a plural, `{1}`": the type is a `List`, `Map`, `Span`, `ReadOnlySpan`, fixed array or text view, with `Untrusted`, `Owned` and `?` looked through (`Untrusted<List<Line>>` is a collection), and the name's last word is a known singular noun.
- "`{0}` holds one `{1}`; name it with a singular noun": the type is not a collection or a number and the name's last word is a plural the checker knows (an irregular plural, a project noun's `forms` entry, or a regular plural of a known noun). `string` is never a collection.

The last word of the name decides (`firstLine`, `lineItems`), or the word before the first particle or function word (`linesByName` is decided by `lines`); a name that starts with one (`byPath`) is not checked. Collectives (`buffer`, `history`, `data`, … and the project's `grammar.collectives`) name a collection without a plural. Not checked: `bool` names (states, BYN5102), numbers named with a plural (a quantity in units: `cents`, `grams`), type parameters, and a collection whose last word is not a known noun (`covered`, `distinct`). A count named like `numLines` is BYN5105, not this.

**Why.** The name tells the reader how many: `for line in order.lines` reads right, `order.line.append(x)` and `order.lines.price` do not (revision 0021 Part 4, [grammar guide](../bayan-grammar.md) §14).

**Example.**

```
public struct Line {
    public i64 grams
}

public struct Order {
    public List<Line> line
    public Line lines
}
```

**Fix.** Make the number agree (the machine fix renames the declaration when a plural or singular is known; rename the callers with it):

```
public struct Order {
    public List<Line> lines
    public Line firstLine
    public List<u8> buffer        // collective: no warning
}
```

**Where this comes from.** Arabic nouns agree in number with what they name (al-muṭābaqa fī al-ʿadad); a collective (ism al-jamʿ) is singular in form and names a group. See the [grammar guide](../bayan-grammar.md) §14.

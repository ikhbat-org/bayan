# BYN1020: `errdefer`

**What.** The keyword `errdefer`.

**Why.** Cleanup kinds are spelled after `defer`: `defer`, `defer failing`, `defer panicking`. `errdefer` was the old spelling of `defer failing`.

**Example.**

```
errdefer (e) log($"rolled back: {e}")
```

**Fix.** Write `defer failing`; the `(e)` binding stays (the machine fix does this):

```
defer failing (e) log($"rolled back: {e}");
```

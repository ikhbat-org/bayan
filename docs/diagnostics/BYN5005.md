# BYN5005: argument passed without its particle

**Why.** A particle is part of the function's name, so the call writes it: `width(2, until: 5)` reads as the declaration does. An argument for a parameter with a particle, passed without it, is reported; this also catches a swapped pair, which the same-type naming rule (BYN2307, retired) used to.

**Message.** `{0}` is passed without its particle `{1}:`

**Help.** add `{1}:` before the argument

**Example.**

```
i64 width(i64 start, until i64 end) => end - start

print($"{width(2, 5)}")
```

**Fix.** Add the particle: `width(2, until: 5)`. The diagnostic carries this fix.

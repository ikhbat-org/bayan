# BYN2236: map literal with an element that is not `key: value`

**What.** A collection literal with a `key: value` element is a map literal, and then every element needs a key. An element without one (a plain value or a `..` spread) has no key to store it under.

**Why.** `["a": 1, 2]` is neither a list nor a map; the compiler does not guess which one was meant.

**Example.**

```
let stock: Map<string, i32> = ["A-1": 12, 3]
```

**Fix.** Give every element a key, or remove the keys to make a list.

```
Map<string, i32> stock = ["A-1": 12, "B-2": 3]
```

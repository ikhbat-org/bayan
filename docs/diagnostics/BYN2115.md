# BYN2115: method modifies `this` without `ref this`

**What.** A method assigns to a field of `this`, or calls a `ref this` member on `this`, but does not declare `ref this` as its first parameter.

**Why.** Members are read-only by default (spec §9). `ref this` in the signature tells the reader, and the compiler, that a call changes its receiver, so calling it on a `let` is an error at the call site instead of a surprise inside the body. The compiler checks the declaration; it does not infer it.

**Example.**

```
struct Counter {
    i64 n

    void bump() {
        n += 1
    }
}
```

**Fix.** Declare `ref this` as the first parameter (the machine fix inserts it):

```
struct Counter {
    i64 n;

    void bump(ref this) {
        n += 1;
    }
}
```

If the method should not change the value, return a new value instead of writing to `this`.

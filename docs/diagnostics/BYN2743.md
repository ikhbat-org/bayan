# BYN2743: operator on a type parameter

**Why.** Type parameters have no constraints, so the body of a generic function or type must be valid for every type it could be instantiated with. A value of a type parameter `T` can only be copied, compared with `==` and `!=`, passed, stored, returned and formatted; arithmetic, ordering (`<`, `<=`, `>`, `>=`), logic and bitwise operators are not available on every type.

**Example.**

```
T add<T>(T a, by T b) => a + b
```

**Fix.** Write the function for the concrete type (`i64 add(i64 a, by i64 b)`), or pass the operation in as data the caller computes.

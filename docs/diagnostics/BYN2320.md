# BYN2320: `requires` or `expects` condition is not `bool`

**What.** A condition has a type other than `bool`. The condition is either a struct field's `requires` rule or a function's `expects` clause. The message reads "a `requires` clause must be `bool`, got `i64`" for both.

**Why.** A `requires` rule checks a field value and an `expects` clause checks the arguments on entry; each panics in every build mode when it is false. Only a `bool` can be true or false (HANDOFF §7).

**Example.**

```
struct P { i64 low requires it }
```

The same code is reported for a function:

```
i32 half(i32 n) expects n {
    return n / 2
}
```

**Fix.** Write the condition the value must meet, such as `it > 0` for a field or `count > 0` for a parameter:

```
struct P { i64 low requires it >= 0 }
```

For the function:

```
i32 half(i32 n) expects n >= 0 {
    return n / 2
}
```

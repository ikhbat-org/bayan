# BYN2320: `requires` clause is not `bool`

**What.** A function's `requires` clause has a type other than `bool`.

**Why.** A `requires` clause is a condition the arguments must meet on entry; the function panics in every build mode when it is false. Only a `bool` can be true or false (HANDOFF §7).

**Example.**

```
i32 half(i32 n) expects n {
    return n / 2
}
```

**Fix.** Write the condition the argument must meet:

```
i32 half(i32 n) requires n >= 0 {
    return n / 2
}
```

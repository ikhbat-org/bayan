# BYN2230: renamed member

**What.** A built-in member is used under its old name: `add` on a `List`, `asString()` on a `StrBuf`, `onPanic` on `Panic`, or a round-3 rename that changes the call's shape.

**Why.** Round 2 gives each idea one name (HANDOFF §11, §12). Ordered collections `append` (unordered ones `add`). A `StrBuf` hands back its text with `finish()`, or lends it with `view`. The old names stay recognised so the compiler can tell you the new one. Sizes keep `length` (round 3 keeps length). Round 3 names the panic hook for its role, `Panic.handler`; spells ranges and lookups with particles (`remove(from:until:)`, `tryGet(at:)`); and drops the `toX`/`asX` members for a view noun (`span`) and the `string(x, as:)` conversion. Decoding bytes is a codec, `Utf8.decode`, and `string(x)` only formats.

| Old | New |
|---|---|
| `list.add(x)` | `list.append(x)` |
| `buf.asString()` | `buf.finish()` |
| `Panic.onPanic = f` | `Panic.handler = f` |
| `list.removeRange(a, b)` | `list.remove(from: a, until: b)` |
| `list.replaceRange(r, items)` | `list.replace(at: r, by: items)` |
| `map.getOr(k, d)` | `(map.tryGet(at: k) ?? d)` |
| `xs.asSpan()` | `xs.span` |
| `n.toHex()`, `n.toBinary()`, `n.toOctal()` | `string(n, as: .hex)`, `.binary`, `.octal` |
| `s.offset(x)` | `s.position(x)` |
| `s.toUtf16()` | `s.utf16` |
| `xs.toList()` | `xs.copy()` |
| `array.toList()` | `array.span.copy()` |
| `string.from(bytes)`, `string.fromUtf8(bytes)` | `Utf8.decode(bytes)` |
| `string.tryFrom(bytes)` | `Utf8.tryDecode(bytes)` |
| `try string(bytes)` | `try Utf8.decode(bytes)` |

**Example.**

```
var xs = List<i64>()
xs.add(1)
var buf = StrBuf()
print(buf.asString())
```

**Fix.** Write the new name (the machine fix does it):

```
var xs = List<i64>();
xs.append(1);
print(buf.finish());
```

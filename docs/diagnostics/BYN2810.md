# BYN2810: `static` interface member

**What.** An interface member is declared `static`.

**Why.** A `static` interface member (`static T parse(string text)`, called as `T.parse(…)` through a constraint) is not supported yet: no part of the compiler port needs it, so it is left out of the first interface subset (spec 006).

**Example.**

```
interface IParse {
    static i64 parse(string text)
}
```

**Fix.** Remove `static` and call the member on a value, or make it a free function:

```
i64 parse(string text) {
    // …
}
```

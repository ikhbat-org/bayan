# BYN1058: `params` or `T...` for a variadic parameter

**Why.** A variadic parameter is written `rest ReadOnlySpan<T> name`: the caller's extra arguments arrive as a read-only span. C#'s `params T[]` and C's `T...` are input forms.

**Example.**

```
i32 sum(params i32[] xs) { return 0 }
i32 total(i32... xs) { return 0 }
```

**Fix.** Write `rest ReadOnlySpan<T>`:

```
i32 sum(rest ReadOnlySpan<i32> xs) { return 0 }
```

The diagnostic carries a machine-applicable fix, and `bayan format` applies it.

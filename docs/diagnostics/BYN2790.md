# BYN2790: pattern binds the same storage more than once in `switch move …`

**Why.** In `switch move x` each pattern binding owns the part it binds. A binding for a whole value and another for a part of it, two bindings on both sides of an `and`, or two bindings of the same field in one property pattern (`{ items: let x, items: let y }`, at any nesting) would own the same storage twice, and a unique value may have only one owner (L006).

**Example.**

```
struct Ledger {
    List<i64> items
}
void keep(move List<i64> xs) { }
void drop(move Ledger l) { }
void inspect() {
    let a = Ledger { items: List<i64>() }
    switch move a {
        case let x and let y:
            drop(move x)
            drop(move y)
        case Ledger { items: let it } whole:
            keep(move it)
            drop(move whole)
        case { items: let x, items: let y }:
            keep(move x)
            keep(move y)
        default:
    }
}
```

**Fix.** Bind the whole value or its parts, not both: `case let x:` or `case Ledger { items: let it }:`, and each field once. Bindings over disjoint parts, such as `{ items: let a, other: let b }` or `.pair(let a, let b)`, are accepted. Without `move`, bindings borrow and any of these patterns is fine.

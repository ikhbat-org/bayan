# BYN1022: compound `unless`

**What.** `unless` with a condition joined by `&&` or `||`.

**Why.** `unless a && b` means "if not (a and b)", which readers get wrong. `unless` is for one plain condition.

**Example.**

```
unless ready && open {
    wait()
}
```

**Fix.** Use `if` with the negated condition in parentheses (the machine fix does this), and simplify it if you like:

```
if !(ready && open) {
    wait();
}
```

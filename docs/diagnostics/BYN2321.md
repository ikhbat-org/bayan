# BYN2321: constant argument violates `expects`

**What.** A call passes a constant argument that makes one of the callee's `expects` clauses false.

**Why.** An `expects` clause is the caller's obligation. A violation is a bug and panics at run time in every build mode; when the argument is a constant, the compiler already knows the call would panic, so it reports it here instead (HANDOFF §7).

**Example.**

```
i32 discount(i32 total, by i32 percent)
    expects percent in 0..=100 && total >= 0
    => total - total * percent / 100

let price = discount(200, by: 150)
```

**Fix.** Pass a value that meets the clause:

```
i32 discount(i32 total, by i32 percent)
    expects percent in 0..=100 && total >= 0
    => total - total * percent / 100

let price = discount(200, by: 50)
```

# BYN2321: constant value violates a `requires` or `expects` contract

**What.** A constant makes a contract false. The contract is either a struct field's `requires` rule, when a struct literal sets the field to a constant that fails it, or a function's `expects` clause, when a call passes a constant argument that fails it. The message reads "`-1` violates `requires it >= 0` of `P`" for both.

**Why.** A `requires` rule or an `expects` clause is an obligation on the value. A violation is a bug and panics at run time in every build mode; when the value is a constant, the compiler already knows it would panic, so it reports it here instead (HANDOFF §7).

**Example.**

```
struct P { i64 low requires it >= 0 }

let p = P { low: -1 }
```

The same code is reported for a function:

```
i32 discount(i32 total, by i32 percent)
    expects percent in 0..=100 && total >= 0
    => total - total * percent / 100

let price = discount(200, by: 150)
```

**Fix.** Pass a value that meets the rule or clause (the help reads "pass a value that meets `requires …`"):

```
struct P { i64 low requires it >= 0 }

let p = P { low: 1 }
```

For the function:

```
i32 discount(i32 total, by i32 percent)
    expects percent in 0..=100 && total >= 0
    => total - total * percent / 100

let price = discount(200, by: 50)
```

# BYN2321: constant argument violates `requires`

**What.** A call passes a constant argument that makes one of the callee's `requires` clauses false.

**Why.** A `requires` clause is the caller's obligation. A violation is a bug and panics at run time in every build mode; when the argument is a constant, the compiler already knows the call would panic, so it reports it here instead (HANDOFF §7).

**Example.**

```
i32 discount(i32 total, i32 percent)
    expects percent in 0..=100
    => total - total * percent / 100

let price = discount(total: 200, percent: 150)
```

**Fix.** Pass a value that meets the clause:

```
let price = discount(total: 200, percent: 50)
```

# BYN2816: an interface is not a type

**What.** An interface name is used as a type on its own: a parameter, local, field, return or type argument.

**Why.** An interface describes what a type provides; it has no size or layout of its own, so there is no value of type `IShape`. An interface may appear in a base list (`struct Circle : IShape`), in a `where` bound, or after `dyn ref`.

**Example.**

```
interface IShape {
    f32 area()
}

void show(IShape s) { }
```

**Fix.** Borrow any conforming value with `dyn ref`, or make the function generic with a constraint:

```
void show(dyn ref IShape s) { }

void draw<T>(ref T s) where T : IShape { }
```

# BYN2787: `trust` needs a reason

**Why.** `trust(x, reason: "…")` clears the `Untrusted` mark on a value, so the reason is the audit trail for why that is safe. It must be written at the call site as a non-empty string literal; a missing, empty, interpolated or variable reason says nothing a reviewer can search for.

**Example.**

```
Untrusted<string> name = Untrusted("x")
print(trust(name, reason: ""))
```

**Fix.** Pass a literal that explains why the value is safe, such as `reason: "checked against the allow list"`.

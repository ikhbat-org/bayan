# BYN2023: wrong number of type arguments

**Why.** Generic types have a fixed arity: `List<T>` and `Span<T>` take one type argument, and a `struct Pair<A, B>` takes two. `ValidationError` takes one too: a bare `ValidationError` names no type, so there is no `T.Field` for its violations (revision 0011).

**Example.**

```
var xs: List<i64, i64>
```

**Fix.** Pass exactly the type arguments the type takes: `fails ValidationError<Order>`.

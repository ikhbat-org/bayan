# BYN2720: unknown enum member

**Why.** An enum lists its members; others do not exist. Besides its members, an enum type has only `count`, `values`, `fromOrdinal` and `parse`.

**Example.**

```
enum Color {
    red
    green
    blue
}

let c = Color.gren
```

**Fix.** Use one of the declared members, or add the member to the enum.

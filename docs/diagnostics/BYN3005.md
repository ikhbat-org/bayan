# BYN3005: `ref` and another use in one call

**Why.** A `ref` argument may be changed by the callee while the callee also reads the same value through another argument, for example a list it is growing and a span over that list (spec §9.4 rule 5).

**Example.**

```
var xs = List<i64>()
void grow(ref List<i64> items, ReadOnlySpan<i64> from) { }
grow(items: ref xs, from: xs)
```

**Fix.** Copy the value into a local first and pass the copy, or split the work into two calls.

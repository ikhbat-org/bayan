# BYN2789: `switch move …` needs a local or a `move` parameter

**Why.** `switch move x` moves `x` into the switch so its pattern bindings own the parts they bind, and `x` is moved from afterwards. Only a value this function owns outright can be moved that way: a local or a `move` parameter. A field or element belongs to its owner, and a plain parameter is borrowed from the caller, so moving it into the switch would leave a half-moved value behind.

**Example.**

```
union Slot {
    empty
    full(List<i64> items)
}
struct Box {
    Slot slot
}
void keep(move List<i64> xs) { }
void inspect() {
    let box = Box { slot: Slot.empty }
    switch move box.slot {
        case .full(let items): keep(move items)
        default:
    }
}
```

**Fix.** Drop `move` and the bindings borrow, as in `switch box.slot`. Declare a parameter `move` to own it. For a collection field, take it into a local first, `let items = box.items.take();`, and switch on that local.

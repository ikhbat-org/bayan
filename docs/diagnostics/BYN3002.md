# BYN3002: borrow outlives its source

**Why.** A `string`, `Span<T>` or `List<T>` that points into a stack buffer, a local array or an arena is only valid until that storage is freed at the end of its block. Storing it in a variable (or list) declared in an outer block would leave the variable pointing at freed memory.

**Example.**

```
var view = ""
{
    let bytes = stackalloc u8[16]
    var sb = StrBuf(bytes)
    sb.append("scratch")
    view = sb.finish()
}
print(view)
```

**Fix.** Move the storage out to the block where the value is used, or copy the data with `.copy(to: alloc)` into an allocator that lives long enough.

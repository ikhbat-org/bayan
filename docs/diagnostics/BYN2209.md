# BYN2209: string concatenation

**What.** `+` (or `+=`) with `string` operands. Strings cannot be joined with `+`, not even constants.

**Why.** `+` on strings would allocate behind your back, and in a loop it is quadratic. Bayan keeps allocation visible: interpolation writes straight into its output or a buffer. One rule for every operand, constant or not, keeps the language small (HANDOFF §12). A string pattern such as `"/api/" + var rest` is not concatenation and stays legal.

**Example.**

```
let name = "x"
let greeting = "Hello, " + name
let path = "/usr" + "/lib"
```

**Fix.** Interpolate the parts (the machine fix rewrites `a + b` to `$"{a}{b}"`, inlining literal text). Two literals become one literal, which stays a constant:

```
let greeting = $"Hello, {name}"
let path = "/usr/lib"
```

To build text in a loop, append to a `StrBuf`: `buf.append($"{a}{b}")`.

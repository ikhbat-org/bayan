# BYN2707: recursive union

**No longer reported since M21.** A union that contains itself by value is now BYN2761, which names the whole cycle and covers structs too. The code stays reserved.

**Why (before M21).** Unions are stored inline, so a union that contains itself by value would have infinite size.

**Example.**

```
union Expr {
    number(i64 value)
    negate(Expr operand)
}
```

**Fix.** Store the inner value as `Owned<Expr>`, in a `List` of the union, or as an index into one.

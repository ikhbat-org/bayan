# BYN2802: interface member does not match

**What.** A struct provides a member an interface requires, but its signature differs: the return type, a parameter's type or modifier, the kind (method or property), `static`, or the `fails` clause. A field standing for a getter must have the getter's type. It is also reported when a default from one base would stand for a member of the same name in another base: add the member to the struct to choose.

**Why.** Callers use the interface's signature. A witness that returns another type, takes other parameters or fails differently cannot stand in for it.

**Example.**

```
union error ParseError {
    empty
}
interface IParser {
    i64 parse(string text) fails ParseError
}
struct Digits : IParser {
    i64 parse(string text) => 0
}
```

**Fix.** Change the member's signature to the interface's:

```
struct Digits : IParser {
    i64 parse(string text) fails ParseError => 0;
}
```

# BYN0010: invalid numeric literal

**Why.** The literal breaks one of the number rules: `_` separators must sit between digits; `0x` and `0b` need at least one digit of the right base; an exponent needs digits.

**Example.**

```
let a = 1__000
let b = 0x
let c = 1e
```

**Fix.** Write `1_000`, `0x0`, `1e3`.

# BYN2227: ambiguous variant

**Why.** When a function can fail with several error sets, a bare `.variant` must name exactly one variant.

**Example.**

```
union error MoneyError {
    invalid
}
union error ParseError {
    invalid
}
void check(i64 n) fails MoneyError, ParseError {
    fail .invalid if n < 0   // both MoneyError and ParseError have `invalid`
}
```

**Fix.** Qualify it: `MoneyError.invalid`.

# BYN1066: prefix pointer type

**Why.** A pointer type is written after its pointee, as in C#: `T*`, and `readonly T*` for a pointee that cannot be written through it. Rust's `*const T` and `*mut T`, and a bare `*T`, are input forms.

**Example.**

```
extern void copy(*const u8 from, *mut u8 to) { }
```

**Fix.** Write the pointer after the type: `readonly u8* from`, `u8* to`. The diagnostic carries a machine-applicable fix, and `bayan format` applies it; a nested `**T` is fixed from the inside out. Pointer types are allowed only in `extern` declarations (BYN1067).

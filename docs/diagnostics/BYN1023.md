# BYN1023: `unless x is null`

**What.** `unless x is null`.

**Why.** It is a double negative; `if x is not null` says the same thing directly.

**Example.**

```
unless user is null {
    greet(user)
}
```

**Fix.** Write `if … is not null` (the machine fix does this):

```
if user is not null {
    greet(user);
}
```

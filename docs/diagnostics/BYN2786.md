# BYN2786: an `Untrusted` value reaches a sink

**Why.** `Io.run` and `Io.runBatch` run commands. `Io.run` involves no shell, but an untrusted program path runs whatever the attacker names, and an untrusted argument can inject an option (`--upload-pack=…` to `git`, `-oProxyCommand=…` to `ssh`) that makes the program run attacker-chosen commands. `Io.runBatch` runs a batch file through `cmd.exe`, which interprets its arguments again. A value that came from outside the program (`Untrusted<T>`, or a list, span or array of them) must not reach either unchecked: the program or path and every argument must be ordinary values.

**Example.**

```
void main() fails IoError {
    let name: Untrusted<string> = Untrusted("x")
    let args: string[1] = [name]
    try Io.runBatch("./build.cmd", args.span)
    try Io.run("git", [name])
}
```

**Fix.** Check the value, then clear the mark with `name.trustUnchecked() because "checked against the allow list"`.

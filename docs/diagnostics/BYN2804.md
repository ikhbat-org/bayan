# BYN2804: not an interface

**What.** A struct's base list (after `:`) or a `where` bound names a type that is not an `interface`: a struct, union, enum or other type.

**Why.** Only interfaces can be conformed to or used as constraints. There is no struct inheritance; a struct that needs another struct's data holds it as a field.

**Example.**

```
struct Point {
    i64 x
}

struct Circle : Point {
    i64 r
}
```

**Fix.** List an interface, or hold the other type as a field:

```
struct Circle {
    Point center
    i64 r
}
```

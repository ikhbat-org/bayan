# BYN0016: interpolated strings nested too deeply

**Why.** An interpolated string may contain an expression that is itself an interpolated string. The lexer bounds this nesting (16 levels) so pathological input cannot exhaust it. Only the first occurrence in a file is reported.

**Fix.** Build the inner text in a local first:

```
let inner = $"{a}-{b}"
let outer = $"[{inner}]"
```

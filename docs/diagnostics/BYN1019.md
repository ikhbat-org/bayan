# BYN1019: parenthesized `for`

**What.** `for (let x in xs)`, `for (var x in xs)` or `foreach (var x in xs)`.

**Why.** Bayan has one loop over a sequence: `for x in xs { … }`. The loop variable is a fresh binding each iteration, so `let`/`var` adds nothing. A `(` after `for` followed by a top-level `let`, `var` or `in` is this input form; `for (a, b) in pairs` is a tuple destructure.

**Example.**

```
foreach (var order in orders) {
    ship(order)
}
```

**Fix.** Write the bare form (the machine fix does this):

```
for order in orders {
    ship(order);
}
```

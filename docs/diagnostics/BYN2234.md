# BYN2234: `while let` on a value that cannot be null

**What.** `while let x = e { … }` loops while `e` is non-null and binds `x` to its value. Here `e` is not an optional (`T?`), so the loop would never stop on its own.

**Why.** The loop's only exit test is "is the value null?"; a value that cannot be null makes the test meaningless and the loop endless.

**Example.**

```
i64 next() => 1
while let n = next() { print($"{n}") }
```

**Fix.** Return `T?` from the source (`i64? next()`) so the loop ends at `null`, or loop with a condition: `while n < 10 { … }`. To bind a value once, write `let n = next();`.

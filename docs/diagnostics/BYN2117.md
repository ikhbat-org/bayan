# BYN2117: `ref this` is not the first parameter

**What.** `ref this` appears in a parameter list after another parameter, or twice.

**Why.** `ref this` is not an ordinary parameter: it marks the member as mutating (spec §9) and stands for the receiver, which is written before the `.` at the call site. Keeping it first makes every mutating signature read the same way.

**Example.**

```
void add(i64 by, ref this) { n += by }
```

**Fix.** Move `ref this` to the start of the parameter list:

```
void add(ref this, i64 by) { n += by }
```

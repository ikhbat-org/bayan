# BYN2033: std module imports a package module

**Why.** A std module (`lib/std/`, shipped with the compiler) is the same source in every package, so it can import only other std modules; a plain `import util` in it would read whatever `util/` the importing package happens to have.

**Example.**

```
// lib/std/a/a.byn
import util
```

**Fix.** Import `std.…` modules only, or move the code into the package.

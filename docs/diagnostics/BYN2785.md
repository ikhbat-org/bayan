# BYN2785: `slot` needs a default value

**Why.** `map.slot(key)` returns a reference to the key's value, inserting a default value first when the key is missing. That needs a default for the value type: numbers, `bool`, `rune`, `string`, optionals, and structs whose every field has an initializer. Enums, unions, lists, maps and other types have no default, so the inserted value would be made up.

**Example.**

```
enum Color {
    red
    green
}

var colors = Map<string, Color>()
colors.slot("sky") = .red
```

**Fix.** Write with `map[key] = value`, which inserts or updates, and read with `map[key]` (panics when missing) or `map.tryGet(at: key) ?? fallback`:

```
colors["sky"] = .red;
let sky = colors.tryGet(at: "sky") ?? .green;
```

or give every field of a struct value type an initializer.

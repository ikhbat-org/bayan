# BYN2007: local shadows another local

**Why.** A local hiding another local of the same name makes code ambiguous to read, so Bayan forbids it in nested scopes too. The one exception is a `let` in the same scope that gives the name a new type (`let count = count.length;`); with the same type it is warning BYN2028.

**Example.**

```
let total = 0
if ok { let total = 1 }
```

**Fix.** Pick a different name.

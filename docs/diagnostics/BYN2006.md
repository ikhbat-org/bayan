# BYN2006: duplicate declaration

**Why.** Every name in a module, struct, parameter list or import list must be unique. Bayan has no overloading.

**Example.**

```
i64 area(i64 w) => w
i64 area(i64 w, i64 h) => w * h
```

**Fix.** Rename one of them; for variants of a function, give each a descriptive name (`areaOfSquare`).

# BYN7001: value not known to be in the state

**Message.** `{0}` needs `{1}` to be `.{2}`, but it is `{3}`

**Help.** check the state with `is` or `switch` first

**Why.** A method with `this is .s`, or a parameter of a state type `T.s`, may run only on a value known to be in that state. Widening is free (`Order.paid` passes where `Order` is wanted), but the struct itself, or a state type listing other states, is not known to be in the one the callee needs.

**Example.**

```
struct Order {
    i64 id
    states {
        draft
        paid(i64 payment)
    }
}
i64 refund(Order.paid order) => order.id
let order = Order.draft { id: 1 }
let any: Order = order
let refunded = refund(any)
```

**Fix.** Match the state with `is` or `switch` before the call, or pass a value whose type already names the state.

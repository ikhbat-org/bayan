# BYN2705: variant used without its payload

**Why.** A variant with payload fields is constructed by calling it with a value for each field. The same holds for a `union error` case in `fail`.

**Example.**

```
union Shape {
    circle(f32 r)
    none
}

let s = Shape.circle

union error CarrierError {
    timeout(i64 after)
    closed
}

void send() fails CarrierError { fail .timeout }
```

**Fix.** Pass the payload: `Shape.circle(1)`, `fail .timeout(after: 30)`.

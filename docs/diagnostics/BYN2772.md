# BYN2772: invalid exit code

**Why.** `@exitCode(n)` sets the process exit code when a failing `main` ends with that variant. Exit codes outside 1 to 255 are truncated or mean success on common systems, and the code must be known at compile time.

**Example.**

```
union error ConfigError {
    @exitCode(300)
    malformed
}
```

**Fix.** Pass one integer constant from 1 to 255, such as `@exitCode(3)`.

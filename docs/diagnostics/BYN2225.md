# BYN2225: not formattable

**What.** An interpolation hole holds a value with no textual form.

**Why.** Interpolation formats primitives, errors, enums, optionals and tuples of them, and structs that define `formatInto(ref StrBuf)`. Structs have no default display (SPEC §6.6): the compiler will not guess a format for you. Spans, lists and arenas have no single textual form.

**Example.**

```
struct Q {
    List<i64> xs
}
let q = Q { xs: List<i64>() }
print($"{q}")
```

**Fix.** Add `formatInto(ref StrBuf)` to the struct, or use `{x, as: .debug}` for the debug form (the struct-literal form, when every field formats):

```
struct Point {
    i64 x
    i64 y

    void formatInto(ref StrBuf out) {
        out.append($"({x}, {y})")
    }
}
```

For a collection, format the elements in a loop, or a summary such as `xs.length`.

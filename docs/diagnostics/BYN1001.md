# BYN1001: expected token

**Why.** The parser needed a specific token at this point (a closing brace, a parenthesis, a name) and found something else. When a block is not closed, the help line names the line where it was opened.

**Example.**

```
void f() {
    let x = 1

void g() {}
```

**Fix.** Insert the missing token. For an unclosed block, add `}` where the block should end.

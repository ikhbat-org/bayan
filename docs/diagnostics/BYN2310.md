# BYN2310: span parameter is never written through

**Why.** A `Span<T>` parameter promises the function may change the caller's elements, so callers can't pass a `string`, `string.bytes` or another read-only view. A function that only reads should say so with `ReadOnlySpan<T>`; a `Span<T>` still converts to it implicitly.

**Example.**

```
i64 total(Span<i64> values) {
    var sum: i64 = 0
    for v in values {
        sum += v
    }
    return sum
}
```

**Fix.** Declare the parameter `ReadOnlySpan<i64> values`.

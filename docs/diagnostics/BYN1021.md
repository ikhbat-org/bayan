# BYN1021: `=` in a literal

**What.** `name = value` inside a struct literal or a `with` literal.

**Why.** A literal names its fields with `:`, the same as a manifest and a property pattern. `=` is assignment, which a literal does not do.

**Example.**

```
let p = Point { x = 1, y = 2 }
let q = p with { y = 3 }
```

**Fix.** Write `:` (the machine fix does this):

```
let p = Point { x: 1, y: 2 }
let q = p with { y: 3 }
```

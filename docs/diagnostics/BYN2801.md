# BYN2801: missing interface member

**What.** A struct lists an interface after `:` but does not provide one of the interface's members that has no default body. A field can provide a getter (`i64 count { get; }`) but not a method: a field named like a required method is reported here.

**Why.** Code written against the interface may call any of its members on the struct; a member without a body has nothing to run unless the struct provides it.

**Example.**

```
interface IShape {
    i64 area()
}

struct Square : IShape {
    i64 side
}
```

**Fix.** Add the member with the signature the interface declares:

```
struct Square : IShape {
    i64 side;

    i64 area() => side * side;
}
```

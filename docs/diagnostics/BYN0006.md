# BYN0006: invalid escape sequence

**Why.** Only a fixed set of escapes exists, so a typo cannot silently become a different character.

**Example.**

```
let s = "bad \q escape"
```

**Fix.** Use one of `\n \r \t \0 \\ \" \'` or `\u{…}` with a hex scalar value. To write a backslash, use `\\` or a raw `"""` string.

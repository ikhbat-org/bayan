# BYN2744: member of a type parameter

**Why.** A type parameter with no `where` clause has no known members: a field, property or method that one type argument has, another lacks. (With a `where T : I` clause, a missing member is [BYN2806](BYN2806.md).)

**Example.**

```
i64 size<T>(T x) => x.length
```

**Fix.** Add `where T : I` naming an interface that declares the member, or take the concrete type the member belongs to.

# BYN1080: optional bound with `is { } k`

A style lint (`optionals.bind`): reported by `bayan check` only, never by `build`, `run` or `test`. Its severity comes from `lints` in `package.byn` (`.suggestion` by default; `.none` silences it, `.error` makes `bayan check` fail). `bayan fix` applies its fix whatever the severity.

**What.** An `if` or `while` condition `X is { } k` that binds an optional. It is not reported inside `&&`, or when the result is used only on a hit and nothing leaves on a miss (unless `X` is a `let` local or a parameter).

**Why.** Bayan has a form for each use: `let k = X ?? exit` when the miss leaves, `x is not null` to narrow a name, and `while let` for a loop. The pattern form nests the hit path for no gain.

**Example.**

```
if (find(xs, at: 3) is { } k) {
    return k * 2
} else {
    return 0
}
```

**Fix.** The machine fix writes, by case:

- the miss leaves with a literal, a name, a case, `continue` or `break`: `let k = X ?? return 0`, and the hit body moves up;
- the miss leaves with anything else: `let k = X`, then `return <fallback> if k is null`;
- `X` is a `let` local or a parameter: `if x is not null`, with `k` renamed to `x`;
- `while (X is { } k)`: `while let k = X`.

```
let k = find(xs, at: 3) ?? return 0
return k * 2
```

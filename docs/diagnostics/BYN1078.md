# BYN1078: comparisons that one pattern says

A style lint (`conditions.patterns`): reported by `bayan check` only, never by `build`, `run` or `test`. Its severity comes from `lints` in `package.byn` (`.suggestion` by default; `.none` silences it, `.error` makes `bayan check` fail). `bayan fix` applies its fix whatever the severity.

**What.** One operand compared with constants two or more times, joined by `||` (`x == A || x == B`) or as an inclusive range (`x >= A && x <= B`). The operand is a name, a field path, or an index path whose every index is a name or a literal; the constants are integers, runes, strings or cases of an enum without fields, all of one kind. Qualified constants and floats are not linted.

**Why.** `is` with a pattern (spec §6.5) names the operand once and states the set; the chain repeats it and hides the shape.

**Example.**

```
return c >= '0' && c <= '9'
let yes = op == .add || op == .sub
```

**Fix.** Write one `is` pattern (the machine fix does it):

```
return c is '0'..='9'
let yes = op is .add or .sub
```

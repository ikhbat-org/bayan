# BYN1016: modifier not allowed here

**Message.** "`{0}` is not allowed here"

**Help.** "put `@sealed` on a struct" (on anything but a struct); "write `@sealed` with no arguments and no `because`" (with arguments or `because`); "put `@positional` on a struct" (on anything but a struct); "write `@positional` with no arguments and no `because`" (with arguments or `because`); "remove `@positional`: a struct with states is built with state literals" (on a struct with a `states` block).

**Why.** Each modifier applies to certain declarations only: `public` to functions, structs and members, `readonly` to fields and structs, `static` to members, and so on. An import, local or top-level function cannot take the modifier shown. `@sealed` and `@positional` belong on a struct and take no arguments and no `because`; a struct with states is built with state literals, so it cannot be `@positional`.

**Example.**

```
public import money
readonly void f() {}

@sealed
void run() {}

@positional(strict)
struct Point {
    i64 x
    i64 y
}
```

**Fix.** Remove the modifier, or put `@sealed` or `@positional`, bare, on a struct without states.

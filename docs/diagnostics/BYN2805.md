# BYN2805: interface listed twice

**What.** A struct lists the same interface more than once after `:`.

**Why.** A struct conforms to an interface once; the second entry adds nothing and usually means another interface was meant.

**Example.**

```
interface IShape {
    i64 area()
}
struct Square : IShape, IShape {
    i64 side
    i64 area() => side * side
}
```

**Fix.** Remove the second entry, or replace it with the interface that was meant:

```
struct Square : IShape {
    i64 side;

    i64 area() => side * side;
}
```

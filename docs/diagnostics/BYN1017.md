# BYN1017: parenthesized condition

**What.** Parentheses around the whole condition of `if`, `unless`, `while`, `switch` or `do … while`.

**Why.** Bayan conditions are bare and their bodies are blocks, so the parentheses carry nothing. One spelling keeps code uniform. They are still allowed when the condition has a struct literal at its top level, where the `{` would otherwise open the body.

**Example.**

```
if (count > 0) {
    print("some")
}
```

**Fix.** Remove the parentheses (the machine fix does this):

```
if count > 0 {
    print("some");
}
```

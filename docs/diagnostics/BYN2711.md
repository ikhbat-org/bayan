# BYN2711: two union cases share a value

**Why.** A case's value is its tag; two cases with the same tag could not be told apart. A case without a value takes one more than the case before it, so it can collide with a later explicit value.

**Example.**

```
union Mode {
    read = 1
    write = 1
}
union Level {
    low = 1
    mid
    high = 2
}
```

**Fix.** Give each case its own value:

```
union Mode { read = 1, write = 2 }
union Level { low = 1, mid, high = 3 }
```

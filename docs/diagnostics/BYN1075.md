# BYN1075: blocks nested too deep

A style lint (`nesting.depth`): reported by `bayan check` only, never by `build`, `run` or `test`. Its severity comes from `lints` in `package.byn` (`.suggestion` by default; `.none` silences it, `.error` makes `bayan check` fail). It has no machine fix.

**What.** A block opens more than 4 levels below the body of its function (or below the top level of a script). It is reported once for each such block, at its `{`.

**Why.** The main path of the code drifts to the right and each level adds a condition to keep in mind.

**Example.**

```
void pack(Order order) {
    if order is .paid {
        for line in order.lines {
            if line.inStock {
                if line.weight > 0g {
                    if line.fits(box) {
                        stow(line)
                    }
                }
            }
        }
    }
}
```

**Fix.** Leave early with `return`, `continue` or `break` (postfix guards):

```
void pack(Order order) {
    return if order is not .paid
    for line in order.lines {
        continue if !line.inStock
        continue if line.weight <= 0g
        continue if !line.fits(box)
        stow(line)
    }
}
```

# BYN2113: recursive struct

**No longer reported since M21.** A struct that contains itself by value is now BYN2761, which names the whole cycle and covers unions too. The code stays reserved.

**Why (before M21).** Structs are stored by value, so a struct that contains itself (directly or through other structs) would be infinitely large.

**Example.**

```
struct Node {
    i64 value
    Node? next
}
```

**Fix.** Store the next node as `Owned<Node>?`, the children in a `List<Node>`, or refer to them by index.

# BYN1033: likelihood word after `unless`

**What.** `unless unlikely …` or `unless never …`.

**Why.** A likelihood word belongs to `if`, where it describes the branch that is written. After `unless` it would describe the negation.

**Example.**

```
unless unlikely ok {
    recover()
}
```

**Fix.** Drop the word (the machine fix does this), or write `if unlikely` with the negated condition:

```
if unlikely !ok {
    recover()
}
```

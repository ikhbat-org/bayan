# BYN5013: particle used twice

**Why.** A particle names one role in a signature, and a call is read by its particles: with two `from` parameters, `copy(from: a, from: b)` no longer says which is which. A particle appears at most once per declaration. Calls need no check, since such a declaration cannot exist.

**Message.** `{0}` uses the particle `{1}` twice

**Help.** group the values in a struct, or choose another particle

**Example.**

```
void copy(from string src, from string backup) {
    return
}
```

**Fix.** Group the values in a struct, or choose another particle for one of them:

```
struct Sources {
    string src
    string backup
}

void copy(from Sources sources) {
    return
}
```

The diagnostic has no machine-applicable fix.

See GRAMMAR: Role marks (docs/bayan-grammar.md §15).

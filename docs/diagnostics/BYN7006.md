# BYN7006: one state written inline

**Message.** `{0} {1} is .{2}` is an input form; write `{0}.{2} {1}` (without a name, in a local annotation or an alias: `{0} is .{2}` is an input form; write `{0}.{2}`)

**Help.** write the state type `{0}.{2}`

**Why.** A value known to be in one state has the state type `T.s`. The inline form `T name is .a or .b` is for two or more states; with one state it is an input form.

**Example.**

```
void ship(Order order is .paid) { }
```

**Fix.** Write the state type: `void ship(Order.paid order) { }`. The diagnostic carries a machine-applicable fix, and `bayan format` applies it.

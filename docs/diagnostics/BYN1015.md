# BYN1015: C-style `for` loop

**Why.** Bayan's `for` iterates over a range or collection; there is no `for (init; cond; step)` form. Ranges cover counting loops and make off-by-one bounds explicit.

**Example.**

```
let n = 3
for (i32 i = 0; i < n; i++) { }
```

**Fix.** Write `for i in 0..n { … }`, or use `while` for anything else.

# BYN2706: unit variant called

**Why.** A variant without payload fields is a value on its own; it takes no arguments, and its pattern has no parentheses. The same holds for a `union error` case.

**Example.**

```
union Shape {
    circle(f32 r)
    none
}

let s = Shape.none()

union error CarrierError {
    timeout(i64 after)
    closed
}

void send() fails CarrierError { fail .closed() }
```

**Fix.** Drop the parentheses: `Shape.none`, `fail .closed`, or `.none` in a pattern.

# BYN1012: expression has no effect as a statement

**Why.** A statement that is only an expression must do something: call a function, `try` or `catch`, or jump with `?? return`. Expressions such as `a + b;` compute a value and throw it away, which is almost always a mistake.

**Example.**

```
x + 1
```

**Fix.** Assign the value (`y = x + 1;`), use it, or remove the statement.

# BYN2311: `var` is never reassigned

**Why.** A `var` says the value will change; a reader has to look for where. When nothing ever assigns it, increments it, passes it by `ref` or `out`, or mutates through it, the `var` is noise, and `let` says what is true. This applies to locals and to `var` pattern bindings alike (spec §7.1, §6.5). Parameters, `for` loop variables and `let` bindings are never reported.

**Example.**

```
union Shape {
    circle(i64 radius)
    empty
}
let prices = List<i64>()
let shape = Shape.empty
var total = prices.length
print($"{total}")

if shape is .circle(var r) { print($"{r}") }
```

**Fix.** Declare them with `let`: `let total = prices.length;` and `.circle(let r)`.

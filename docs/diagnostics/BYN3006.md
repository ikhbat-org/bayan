# BYN3006: moved while borrowed

**Why.** Moving a value (`move s`, a `move` argument, `return move s`, `switch move s`, or `.take()` on a `List`, `Map`, `StrBuf` or optional) hands its storage to a new owner, which may grow, change or free it. A span or `dyn ref` that still points into the moved value would read freed or changed memory (spec §9.4 rules 5 and 6).

**Example.**

```
struct S {
    List<i64> xs
}
var s = S { xs: List<i64>() }
let view = s.xs.mutableSpan()
var t = move s
print($"{view[0]}")
```

**Fix.** Finish using the borrow before the move, or copy what it needs first.

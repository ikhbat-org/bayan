# BYN2808: interface cannot be used with `dyn`

**What.** `dyn ref I` names an interface that has a generic method or an associated type (`type Item;`). The diagnostic names the first such member.

**Why.** A `dyn ref` call goes through a table with one entry per member, built once for each conforming type. A generic method has no single entry (each type argument is a different function), and an associated type has no single type for callers to use: both depend on information only a constraint provides (spec 006, handoff Q93).

**Example.**

```
interface ICursor {
    type Item
    Item peek()
}

void walk(dyn ref ICursor c) { }
```

**Fix.** Use a `where` constraint, which keeps the conforming type known at compile time:

```
void walk<T>(ref T c) where T : ICursor { }
```

# BYN2763: generic type needs ever-deeper instances of itself

**Why.** Instantiating a generic struct or union declares its members, and a member whose type is the same template at larger type arguments needs another instance first. When each instance needs a deeper one (`G<i64>` needs `G<Owned<i64>>`, which needs `G<Owned<Owned<i64>>>`, and so on), there is no end to them. The checker stops after 64 nested instances and reports the template. Unlike [BYN2761](BYN2761.md), `Owned<…>` or `List<…>` around the member does not help: the instances are needed whatever holds them.

**Example.**

```
struct G<T> {
    List<G<Owned<T>>> g
}
let x = G<i64> {}
```

**Fix.** Give the member the same type arguments as the type it is in (`List<G<T>> g`), or a type that does not name the template.

# BYN2803: missing associated type

**What.** An interface declares `type Item;`, and a struct listing it does not bind `type Item = …;`.

**Why.** The interface's members mention `Item`; without a binding the struct's members cannot be checked against them, and generic code cannot know what `T.Item` is.

**Example.**

```
struct Digits : IIndexable {
    i64 count => 3

    i64 get(i64 index) => index * 10
}
```

**Fix.** Bind the associated type to the type the members use:

```
struct Digits : IIndexable {
    type Item = i64;

    i64 count => 3;

    i64 get(i64 index) => index * 10;
}
```

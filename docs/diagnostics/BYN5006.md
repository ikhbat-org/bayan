# BYN5006: parameter needs a particle

**Why.** A function has one unlabeled required parameter, the object; every other required parameter starts with a particle that names its role (BYN5004). This code marks each parameter that needs one. The receiver of a method is not the object, so `record(ref this, i64 amount, i64 fee)` has two unlabeled parameters.

**Message.** `{0}` is a required parameter besides the object and needs a particle

**Help.** label it with `from`, `to`, `until`, `through`, `at`, `by`, `for` or `as`

**Example.**

```
struct Ledger {
    i64 total

    void record(ref this, i64 amount, i64 fee) {
        total += amount - fee
    }
}
```

**Fix.** Choose the particle by meaning: a source or start takes `from`, a destination `to`, an exclusive end `until`, an inclusive end `through`, a position `at`, a replacement `by`:

```
    void record(ref this, i64 amount, by i64 fee) {
        total += amount - fee
    }
```

The diagnostic has no machine-applicable fix.

See GRAMMAR: Role marks (docs/bayan-grammar.md §15).

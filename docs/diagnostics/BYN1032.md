# BYN1032: retired, `if !x` is no longer rewritten

**No longer reported.** BYN1032 asked for `if !x { … }` with no `else` to be written `unless x { … }`. Design round 3 §5 dropped it: the rewrite replaced one paraphrase with another for no gain, and each boolean spelling reads well in some code. `!`/`&&`/`||` and `not`/`and`/`or` are both allowed. The code stays reserved: never reuse it.

**Example.** Both are accepted:

```
if !done {
    work()
}
if not done {
    work()
}
```

**Fix.** None needed.

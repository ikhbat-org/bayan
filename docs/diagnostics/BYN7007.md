# BYN7007: unknown state

**Message.** `{0}` has no state `.{1}`

**Help.** check the states declared in `{0}`

**Why.** A state type `T.s`, a receiver `this is .s`, a `becomes .s` clause, a `become .s` or a state literal `T.s { … }` must name a state from the struct's `states { … }` block.

**Example.**

```
struct Order {
    i64 id
    states {
        draft
        paid(i64 payment)
    }
}
void refund(Order.refunded order) { }
```

**Fix.** Use one of the declared states, or add the state to the struct's `states` block.

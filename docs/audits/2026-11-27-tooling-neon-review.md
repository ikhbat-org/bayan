## Part 2: T4 (`bayan mcp`)

1. **MCP protocol revision:** Unsure whether a newer stable revision shipped in 2026 after `2025-11-25` (no web access to verify). Check the official MCP spec before pinning; negotiate `protocolVersion` in `initialize` and record the pinned revision in `docs/tooling.md`.
2. **Stdio framing (input):** Do not use `Io.stdin.readAllBytes` (blocks until EOF). Build a buffered line reader on `Io.stdin.read(to:)` using the pattern in [transport.byn](../../editors/language-server/src/transport/transport.byn): a fixed 64 KiB `List<u8>` buffer with `pos`/`filled` indices refilled via `Io.stdin.read(to: input.mutableSpan())`.
3. **Line splitting and bounds:** Accumulate bytes until `0x0A` (`\n`), strip a single trailing `0x0D` (`\r`), and skip blank lines. Enforce a hard max line length (per [memory-leaks.md](../../docs/memory-leaks.md)); if exceeded, drain through `\n` and return JSON-RPC `-32700` rather than growing unboundedly.
4. **Stdio framing (output):** Write compact single-line JSON (no unescaped `\r`/`\n`, as `JsonWriter` produces in [json.byn](../../editors/language-server/src/transport/json.byn)) followed by `\n` via `Io.stdout.write`; write all diagnostics/logs to `Io.stderr.write` only.
5. **Flush behavior:** `byn_io_read_stdin_some` ([bayan-rt.c](../../runtime/bayan-rt.c)) calls `byn_stdout_flush()` before blocking on stdin, so each reply flushes automatically before waiting for the next request.
6. **Memory and child bounds:** Handle each request inside `using let arena = Arena()` (since `General` never frees, [memory-leaks.md](../../docs/memory-leaks.md)), spawn child `bayan` via `Io.run` with `timeout:` so stdout/stderr stay bounded by `BoundedCapture` ([bayan-rt.h](../../runtime/bayan-rt.h), Rule 4), and add a long-lived RSS bound test (Rule 8).
7. **Path-inside-cwd resolution:** Resolve both root (`Fs.realPath(".")`) and target (`Fs.realPath(input)`) via [bayan-rt.c](../../runtime/bayan-rt.c) (`realpath` on POSIX, `GetFinalPathNameByHandleW` on Windows), which normalizes `..` and resolves symlinks.
8. **Path edge cases:** Reject empty strings, NUL bytes (avoids `Path.fullPath` panics at [bayan-rt.h](../../runtime/bayan-rt.h)), and `Fs.realPath` failures (`notFound` is a valid tool error because all path-taking T4 tools operate on existing inputs; `bayan_explain` takes a code, not a path).
9. **Path containment check:** Require `real == root` or `real` starts with `root + sep` (handling roots already ending in `sep`, e.g. `/` or `C:\`) so `/repo` cannot match `/repo-evil`. Compare case-insensitively on Windows.
10. **Child binary lookup:** [bayan-rt.h](../../runtime/bayan-rt.h) has no `selfExe` builtin; resolve the child CLI from `BAYAN_EXE` if set, else `"bayan"` on `PATH`.
11. **Driver subcommand (`src/driver/`) pros:** Matches T4's `bayan mcp` UX directly and ships inside the single `bayan` binary without adding a third binary to [package.sh](../../scripts/release/package.sh) or `scripts/dist.sh`.
12. **Driver subcommand cons:** `src/driver/` has no JSON parser (`json.byn` lives in `editors/language-server/src/transport/`); duplicating it grows `src/driver` and pressures the `bound: check of the driver` RSS cap ([memory-leaks.md](../../docs/memory-leaks.md)). Editing `usageText` in [main.byn](../../src/driver/main.byn) also alters `--help` output against §0.1 byte-identical checks.
13. **Separate `tools/` (or `editors/`) program pros:** Preserves byte-identical `bayan` binaries and output (§0.1), avoids in-flight `src/driver/` merge conflicts and RSS growth, and can reuse the LSP `json.byn`/`transport.byn` patterns directly (matching how `bayan-lsp` is built separately).
14. **Separate program cons:** Does not expose `bayan mcp` directly; shipping it requires wiring a third binary (`bayan-mcp`) into `release.yml`, [package.sh](../../scripts/release/package.sh), and `scripts/dist.sh`, or adding a thin `case "mcp":` exec shim in `src/driver/main.byn`.
15. **Recommendation:** Implement as a separate program under `tools/` (or `editors/`) first to keep `src/driver/` untouched and reuse the LSP transport/JSON patterns; add a minimal `case "mcp":` shim in `src/driver/main.byn` only if single-command `bayan mcp` UX is required before a shared std JSON module exists.

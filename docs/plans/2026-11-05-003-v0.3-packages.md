## Items

| # | Lesson | Change | Done when |
|---|---|---|---|
| 1 | S02 | Verify the sandbox: no install scripts. Comptime and generators read only literal in-package paths and get no `net`, `process`, `env` or `fs` writes | One compile-fail golden for each escape attempt |
| 2 | S04 | Lockfile `package.lock.byn` in Bayān struct-literal syntax, the same as `package.byn`. It records exact versions and content hashes. Publishes are signed and recorded in an append-only transparency log | A tampered archive fails `bayan build`; every publish has a log entry |

| 4 | S05 | Scoped names `owner/package`. Publishing checks for look-alike names (edit distance and confusable characters, including Arabic and Latin look-alikes, matching the bidi-safe lexer) and needs explicit confirmation | Fixture: a look-alike name is refused without confirmation |
| 5 | S07 | `bayan dependencies`: the dependency tree, the size of each package, and the effects granted to each | Output on Sūq's manifest |
| 6 | S08 | `bayan dependencies --sbom` writes a CycloneDX SBOM (decided 2026-11-05) from the lockfile | Validates against the CycloneDX schema |
| 7 | G02 | `bayan migrate --edition <name>` applies edition fix-its, including R4.3's `DeprecatedUse` and `DeprecatedRemoved` | Migrates a fixture project across an edition with no manual edits |

## Naming note

`bayan migrate cs` (round-4 draft, C# migration) and edition migration share one command, so the edition form takes a flag: `bayan migrate --edition <name>`. If SPEC §21.2 has already fixed a different shape, keep it and report the conflict.

## Open: registry hosting

Package scopes and the registry URL end up in every lockfile, so moving the registry later breaks existing lockfiles.

- Must be decided before the first publish.
- Recommendation: the Ikhbat foundation, decided together with the language name and domain.
- This handoff builds everything except the hosted service until that decision is made.

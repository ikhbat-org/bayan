## Naming note

`bayan migrate cs` (bayan-library-tiers.md §10, C# migration, post-v1) and edition migration share one command, so the edition form takes a flag: `bayan migrate --edition <name>`. If SPEC §21.2 has already fixed a different shape, keep it and report the conflict.

## Open: registry hosting

Package scopes and the registry URL end up in every lockfile, so moving the registry later breaks existing lockfiles.

- Must be decided before the first publish.
- Recommendation: the Ikhbat foundation, decided together with the language name and domain.
- This handoff builds everything except the hosted service until that decision is made.

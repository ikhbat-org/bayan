- J2 **`for (a, b) in m` vs old `for (let x in xs)`**: after `for (`, if the paren group contains `let`/`var`/`in` at depth 0 → BYN1019 input form; else a tuple destructure. Mark reversible.

Scaffold templates and `new/*.tree` goldens still use `assert(...)`; spec §20 and older docs still say "assertion failed".
- Left as written on purpose: `docs/bayan-handoff-addendum-002.md:47` (`for (let m in moves)`, historical record); the BYN2709–2711 pages' `read = 1` (union case value declaration, not a field initialiser); `parse/contextual-keywords.byn` `set.add(1)` and `run/owned-expr.byn` `.add` (a union variant).

### Judgment calls made during implementation

- BYN2028 wording is "`{0}` shadows an earlier `{0}` of the same type `{1}`": the plan text produced "a `i32`" (article error).
- L001 and L002 laws carry `timeout: 1800` (user chose 2026-10-22); the 600 s default timed out under load.
- `for try` works now over a fallible sequence (a value with `T? next() fails E`) instead of reporting BYN2022; iterating one without `try` is BYN2221 with a fix-it. Spec §7.4 changed to match.
- `Panic` is a builtin with `p.message` (string), copied into a 1024-byte thread-local buffer and truncated beyond that.
- `catch switch`: an arm may name a whole error set; an `and` pattern whose right side always matches covers its left side; BYN2410 lists an unhandled set by name; BYN2411 for a set the call cannot fail with. `error set` parses both `,` and `|` until BYN1029 lands.
- BYN2410 help on a switch expression over a local union names the missing arms, because `_` there raises BYN2712. Other switches keep the `_` advice.
- Narrowing applies to `let` locals and by-value or `in` parameters only; not `var`, `ref`/`out`/`move` parameters, `when` guards, `?:` or `do`/`while` conditions.
- `move b` and `switch (move b)` on a narrowed local move the underlying local and keep the narrowed type.
- A brace-first scan (`BodyBraceFirst`) stops `RejectPostfixAfterCompound` from flagging `if a {} if b {}` on one line.
- Overflow: fast and safe flag sets are now identical; the `bayan-rt.h` header comment was reworded.
- Manifest `style` is a data-only object; the removed golden `diag/catch-switch-without-binding` tested the old rejection.
- `[Cases]` values must be literals (number, string, char, bool, `null`, `.case`, signed or parenthesised literal); a named list gives BYN2774 with a tuple-literal hint. A bare value is allowed for a single parameter. BYN2773 keeps the plan wording ("gives 1 values").
- Naming checker: a `bool` member ending in `-ed` gets BYN5102 only; a `ref this` member ending in `-ed` is not reported; BYN5102 skips names starting `contains`, `equals`, `matches`, `startsWith`, `endsWith`, `try`; BYN5101 uses a 29-word noun list.
- Renames forced by the checker: selfhost `atLineStart` → `isAtLineStart`; diag goldens `counted()` → `spanAndCount()` and `doubled()` → `twice()`.
- Help texts reworded to start with a verb (005 R15), `spread` added to the help verb list.
- Size stays `length` (user, round 3): the `count` rename was reverted in about 100 files by token, and BYN2230 maps only `add` and `asString()`.
- J6: structs are formattable only through `formatInto`; run goldens that interpolated a struct got a `formatInto` writing the old text, so their `.stdout` files are unchanged.
- BYN2209 reports constant operands too (`"a" + "b"`), not only non-constant ones.
- Loop variables have no `var` form: `for x in xs` binds immutably and the BYN1019 fix drops `var`; BYN2104's help says to copy into a local `var`. `diag/map-copy` was changed to match.
- BYN2026 is retired, not reused, and its check was removed from `Binder.cs`; the page stays as history.
- BYN1017 is skipped when the parenthesized group has a top-level `{` (brace exception); `if (x is { }) …` keeps its parentheses in help text.
- BYN1032 (`if !x` without `else` to `unless x`) skips `&&`/`||` operands, a double `!` and `is null`.
- BYN1031 fix rewrites `T!E name(…)` to `name(…) fails E`; `T!(A, B)` is accepted as the shorthand.
- Power-assert: each shown sub-expression is spilled to a temp once so it is evaluated once; a lazy side gets a bool flag and its column is drawn only if the flag is set.
- `assert(x);` still parses, as `assert (x);`; `assert` in expression position is BYN1002.

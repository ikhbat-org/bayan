# v0.2a: Fast loop, inspection, testing

Status: open (not started; its gate is the round-4 batch, and no item is in a CHANGELOG section).

Date: 2026-11-05.

- **Gate:** the round-4 batch is merged, and A2's baselines exist.
- **Rule:** no syntax changes. Everything here is tooling, library or optimizer work. New diagnostics take numbers from the renumbered ranges.
- **CLI naming:** commands and flags are full words (GRAMMAR's no-abbreviation rule).

## Gate thresholds (accepted 2026-11-05)

| Gate | Threshold |
|---|---|
| `bayan check` vs full build | ≤ 25% |
| One-file rebuild vs checking that file | ≤ 2× |
| Benchmark regression | > 5% slower on the median of 5 runs fails |
| Binary size | > 3% growth fails |
| Clean compile of the self-hosted compiler | > 5% slower fails |

## Noise traps and the mitigation each step must carry

1. **Cache key.** `t9Key` (`src/driver/cache.byn:304-330`) hashes the compiler command, identity and flags, not the wrapper's environment. Every matrix cell gets its own `BAYAN_CACHE`, and `cc-wrap.sh` prints its extra flags on `--version` so the identity probe differs too.
2. **Compile vs link.** The runtime is compiled with `-c` and linked separately (`src/driver/cc.byn:194-206,256-288`). `cc-wrap.sh` passes `-fsanitize=*` to both and compile-only flags only with `-c`. It strips the exact `-w` argument, never a substring.
3. **Warnings.** The driver compiles `main.c` in the link call (no `-c`), so `HARDEN_COMPILE_ONLY` never reaches it; step 4's `-Werror=` pass uses `HARDEN_CFLAGS` (`-Werror=` is ignored at link). Stripping `-w` without a filter floods findings with unused-variable/label noise from generated C. Use an allowlist of `-Werror=` bug classes (implicit-function-declaration, return-type, incompatible-pointer-types, int-conversion, uninitialized, sequence-point, shift-count-overflow, strict-aliasing, format) on `main.c`; `bayan-rt.c` separately under `-Wall -Wextra`.
4. **zig cc is clang.** On the host, gcc vs clang is the differential pair; zig only for cross targets (musl, wasm32), where libc differences are expected.
5. **`-fwrapv` hides signed overflow from UBSan.** UBSan pass 1 keeps the toolchain flags (shifts, `INT_MIN/-1`, alignment, bounds, null). Pass 2 strips `-fwrapv` to expose any checked arithmetic the emitter lowered as a raw C operator.
6. **LSan.** `General`, `StrBuf` growth, `List` tails, caught panics and script arenas never free (Q31, `docs/memory-leaks.md:78-86,176`). Run with `detect_leaks=0` until Q31 is done; no suppression file. `detect_stack_use_after_return=0` because panics use `longjmp`.
7. **Arenas hide object boundaries** from ASan and Fil-C. A runtime build switch that routes arena allocations to separate `malloc` calls under `__SANITIZE_ADDRESS__`/`__FILC__` is a runtime change: it waits for the in-flight branches and is a finding-driven follow-up, not part of step 2.
8. **The compiler under a sanitizer.** `scripts/bootstrap-build.sh`'s `CC` builds stage 0 only. To instrument stage 1, stage 0 builds it with `BAYAN_CC=cc-wrap.sh`. Raise `BAYAN_CC_TIMEOUT_S` for Fil-C (2–5× slower).
9. **Fil-C.** Audit `bayan-rt.c` for inline asm and integer-to-pointer casts first. Fil-C ships musl, so its self-host C is compared against a musl-built compiler if libc float/sort output differs.
10. **Comparing runs.** Leave out `// mode: debug` cases and `byn_own`-dependent output before comparing across modes. For expected traps, compare the Bayān trap line and a non-zero exit, not the signal number.
11. **H7 mutants** count only when rejected with the exact expected code; a mutant rejected for a parse or type error is discarded, not counted.

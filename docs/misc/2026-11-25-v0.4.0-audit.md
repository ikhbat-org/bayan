## Fixed on dev (unpushed)

- **04 #3, HIGH: raw-string text on the closing line was dropped.** Fixed in `src/parser/literals.byn:34`, case `run/raw-string-closing-line`. The frozen C# golden encoded the same bug, so the change is recorded in `tests/cases/DIVERGENCES.tsv`. Merge 06362d308.
- **08 #2, HIGH: a branch ending in `fail` did not narrow the rest of the block.** `return` did, so valid code got BYN2208. Fixed in `exits()` in `src/semantics/binder2.byn`, case `run/fail-narrows`, branch `fix/fail-narrows`. `csharp-final` `Binder.cs` `Exits` had the same gap.
  - **User-visible change:** after `fail … if x is null`, the value `x` is narrowed. A later `x ?? d` is now BYN2210, as it already was after `return`. One such use in `src/sabk/macho/writer.byn:262` was fixed on the same branch.
- **Found by law L023 while proving the raw-string fix:** a getter named like a method panicked the checker. It now reports BYN2006. Case `diag/getter-named-like-method`, merge b8cdcad19.

## Owner decisions

- **Region and ownership HIGHs (chunk 05, 8 rows) and effects/typestate HIGHs (chunk 06, 3 rows):** these are soundness gaps in the borrow, region and typestate analyses. None of them is a one-line fix. Each needs a plan, such as a fixed-point loop over iterations, `defer` move tracking, and state facts that survive `becomes`.
- **Evals sandbox HIGHs (chunk 16):** the host-side launcher writes through paths the candidate controls, and pending tests count as passing. These matter before the evals are trusted for scoring.
- **LOW rows:** each one is copied to `work/todo.md` with a pointer back to this report.

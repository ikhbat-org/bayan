# 011 cross-file entry points

One line per cross-file signature, as `- <task> <file>: <signature>  ← <C# file:line> <C# name>`, with `<file>` relative to
`selfhost/`. `SelfhostEmitterApiTests.EveryIndexedEntryPointExists` checks that each signature appears verbatim at the start
of a line in its file, after an optional `public `, and followed by nothing, ` =>` or ` {`; an effect clause is part of the
signature. Where no C# line is known the reference is the Bayan file and line (the semantics functions the emitter reads
were ported in 010; the emitter files name the C# method they stub).

`types.byn` and `symbols.byn` and are not indexed here.

# 027 — Tasks

Status: draft
Release: unscheduled (phase 1 planned for 0.5.0)
Sources: `./027-spec.md`

Plan: ./027-plan.md

Phase 1 only (plan T1–T19); R15–R19 and P5 get their tasks with the phase 2 and phase 3 plans, except the law pairs
at the end. Tasks run in order; `after:` names the tasks each one needs. `files:` lists the files edited by hand, at
most two. Generated files (`src/driver/runtime.byn` and `src/driver/diagdocs.byn` from
`scripts/selfhost/gen-driver-files.sh`, `docs/DIAGNOSTICS.md` from `scripts/docs/gen-diagnostics.sh`, `bootstrap/`
from `scripts/selfhost/land.sh`, `docs/specs/README.md` from `scripts/docs/gen-spec-index.sh --write`) are
regenerated by the task that changes their source and are not counted. `cases:` lists golden cases under
`tests/cases/<kind>/`, each a `.byn` plus its expected files; expected files are written with `BAYAN_UPDATE=1 bayan
test tests/cases --only '<kind>/<name>'` and read against the spec, never typed by hand, and every case named here
is new. A case whose feature waits on a later task lands with a `.pending` file naming that task. `src/` changes
land through `scripts/selfhost/land.sh`. An explain page lands in the same landing as the code that makes its code
live (`scripts/ci/diagnostic-codes.test.sh` needs both). Timing cases scale with `BAYAN_TEST_TIME_SCALE`. Full,
Windows and benchmark runs go to wp1 or wlt1. "(new)" marks a path the plan creates; "(new, named here)" marks a
path the plan needs but does not name (see Questions).

# 018 cross-file entry points

One line per cross-file signature, as `- <task> <file>: <signature>  ← <C# file:line> <C# name>`, with `<file>` relative to
`selfhost/`. Each signature appears verbatim at the start of a line in its file, after an optional `public `, and followed by
nothing, ` =>` or ` {`; an effect clause is part of the signature. Where no C# line exists the reference is the spec requirement.

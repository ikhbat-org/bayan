## Approach
Three small changes, in this order, each in both compilers while the parity harnesses are the gate (spec R19):

1. Parse `extensible` after `union error` and carry one boolean on the error set declaration and its symbol. A composition takes the flag from its members when the symbol is built.
2. In the switch exhaustiveness check, where BYN2410 is reported today, ask first whether the subject set is extensible. If it is and no fallback arm is present, report BYN2412 and skip the case-by-case check for that set.
3. Mark the built-in `IoError` source `extensible`, then fix every switch the new error reports in the repository.

Step 3 is last so that steps 1 and 2 land with a green suite on user sets alone, and the breaking part is one change that can be read on its own.

The spec text goes first of all, as revision 0025, so the code is built from the document (`docs/revisions/README.md`).

Nothing in the emitter, the runtime or the error table changes. The flag is read only by the checker.

## Risks & mitigations
- The repository has more switches over `IoError` than the one known case. The report counts 37 `IoError e =>` arms in `src/`, which already pass. Mitigation: T8 compiles `src/`, `lib/`, `tools/`, `examples/`, `evals/` and every `tests/cases/` input and fixes each BYN2412 site in the same change; the count goes in the progress log.
- A `run-c.sha256` line outside the three expected cases changes. That means the flag reached the emitter. Mitigation: R22 stops the work; T9's done-when is a line count from `git diff --stat`.
- A set arm is not accepted on a composed subject (OQ6). Mitigation: T5 probes before writing the composed case, and the label text is narrowed if needed; the spec default covers it.
- 019a lands mid-work. Mitigation: the check at the start of T3; both branches are stated in R19 and R20.
- The two compilers word the diagnostic differently. Mitigation: the `.diag` files are written from C# and the self-hosted compiler must match them byte for byte through `SelfhostSemanticsHarness`.
- Users of 0.3.x break on upgrade. That is the intent (G4), once. Mitigation: the changelog entry shows the one-line fix, and the explain page has it too.

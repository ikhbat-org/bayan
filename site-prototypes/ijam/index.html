One form, one meaning.

Bayan (بيان) is a value-oriented language that compiles to native code. No runtime, no garbage collector, no exceptions.

Compile your first program Read the docs

Familiar to C#, answerable to C

Bayan is derived from C#, with the parts that need a runtime taken out. Data is structs, values live on the stack, in arenas or in .rodata, and every cost is visible in the source.

  • The compiler writes C, then zig cc makes the native executable.
  • Failure is a value: fails E in a signature, try and catch at the call.
  • Memory safety is not a build mode. Bounds and region checks apply in every build.
  • The bootstrap compiler is C# on .NET 10, NativeAOT. Self-hosting is in progress.
enum Kind {
    word
    symbol
}

enum Token(string text, i32 precedence, rune first, bool keyword, Kind kind) {
    ifKeyword("if", 0, 'i', true, .word)
    plus("+", 2 * 3, '+', false, Kind.symbol)
    star("*", -(1 - 8), '*', false, .symbol)
}

for t in Token.values {
    print($"{t} '{t.text}' {t.precedence} {t.first} {t.keyword} {t.kind}")
}

Why the dots

Early Arabic script was ambiguous: one shape could stand for several letters. The dots, iʿjām, were added so that each shape means one thing.

Bayan holds itself to the same rule. A construct has one spelling and one meaning. A second spelling is rejected, and bayan format rewrites it with a fix-it.

The hoopoe of Sūrat an-Naml (27:20–22) returns with news that is certain and clear. The compiler aims to do the same: what went wrong, where, why, and how to fix it.

From nothing to a running program

The tutorial builds the compiler, writes hello.byn, runs it, then breaks it on purpose and reads the error.

$ bayan run hello.byn
Hello, world!

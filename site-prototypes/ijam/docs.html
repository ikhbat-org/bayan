Enums

An enum is a closed set of named values. Each value is a small integer tag, and any data attached to it sits in a constant table.

Spec §3.13. Enums (Java-style). This page follows the section and quotes programs from the golden tests.

Associated data

List the fields after the enum name, then give each member its values in the same order. The data must be constant, so the compiler can place it in .rodata.

const gravitational: f64 = 6.67300e-11

enum Planet(f64 mass, f64 radius, string label) {
    mercury(3.303e23, 2.4397e6, "the swift")
    venus(4.869e24, 6.0518e6, "the bright")
    earth(5.976e24, 6.37814e6, "home")
}

f64 surfaceGravity(Planet p) => gravitational * p.mass / (p.radius * p.radius)

From tests/cases/run/data-enums.byn.

Declarations are type-first. f64 surfaceGravity(Planet p) puts the kind first and modifiers after. Bindings do the reverse: let w: Grams. See spec §0, principle 12.

Generated members

Every enum gets these without being asked:

MemberMeaning
lengththe number of members (the test below calls it count)
valuesall members, in order
name, ordinalthe member's name and its position
parsename to member, by perfect hash
fromOrdinalposition to member, returning T?
 
print($"count {Planet.count}")
for p in Planet.values {
    print($"{p.ordinal} {p.name} {p.label}")
}
print($"{Planet.fromOrdinal(1)} {Planet.fromOrdinal(3)} {Planet.fromOrdinal(-1)}")
print($"{Planet.parse("earth")} {Planet.parse("Earth")} {Planet.parse("pluto")}")
count 3
0 mercury the swift
1 venus the bright
2 earth home
venus null null
earth null null

Adapted from data-enums.byn, which prints more fields per planet. The spec names the member length and the test uses count; the two disagree.

Spec §3.6. Optionals. fromOrdinal and parse return an optional, so a missing member is null, never an exception. Spec §3.13 also lists EnumMap<T, V>, an inline array keyed by the enum.

Switching

A switch over an enum names each member once. Members may share an arm with or, and a leading dot lets the target type supply the enum name.

string climate(Planet p) => p switch {
    .mercury or .venus => "hot",
    .earth => "mild",
}
Spec §6.5. Patterns. §7.5. switch statements.

Diagnostics

Name a member that does not exist and the compiler points at it and suggests the nearest one.

enum Color {
    red
    green
    blue
}

let c = Color.gren
error BYN2720: `gren` is not a member of `Color`

  7 │ let c = Color.gren
    │               ^^^^
    │
  help: did you mean `green`?

From tests/cases/diag/unknown-enum-member, first case only.

An enum with no members is also an error, BYN2722, with the fix stated: add the members, or remove the enum.

Spec §0, principle 6. Errors explain what, where, why and how to fix. bayan explain BYN2720 prints the long form.

Limits

  • There is no cast from an integer to an enum. Use fromOrdinal, which can say no.
  • Public enums are closed unless marked extensible, which forces callers to include a fallback case.
  • enum open allows unknown values, for C interop only.
  • There is no flags construct. A Set of a payload-free union with at most 64 cases is a single bitmask (not in v0.1).
Spec §3.12. Unions, for cases that carry different data per variant.

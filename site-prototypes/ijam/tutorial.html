Your first Bayan program

Build the compiler, write one line, run it, then make a mistake and read what the compiler says.

  1. 1

    Get the compiler

    Bayan is built from source for now. You need the .NET 10 SDK, and zig on your PATH, which the compiler uses as its C compiler.

    $ git clone https://github.com/ikhbat-org/bayan
$ cd bayan
$ dotnet publish src/Bayan.Cli -c Release -r osx-arm64 -o tmp/publish
$ ./tmp/publish/bayan --version

    Change osx-arm64 to your platform's runtime identifier, and put the bayan binary on your PATH. Then ask it to check its surroundings:

    $ bayan doctor

    doctor checks the C compiler, zig, git and the build cache, and prints a fix for anything missing.

  2. 2

    Write hello

    Save this as hello.byn. There is no main and no semicolon; a file may start with statements.

    print("Salam, world!")
  3. 3

    Build it

    This compiles to C and then to a native executable.

    $ bayan build hello.byn -o hello
  4. 4

    Run it

    $ ./hello
Salam, world!

    To build and run in one step, use bayan run hello.byn.

  5. 5

    Read an error

    Replace hello.byn with a program that has a typo. It defines count and then asks for cout.

    let count = 1
print($"{cout}")
    $ bayan check hello.byn
    error BYN2001: `cout` is not defined
  --> hello.byn:2:10

  2 │ print($"{cout}")
    │          ^^^^
    │
  help: did you mean `count`?
    │ 2 │ print($"{count}")
    │   │             +

    The message says what is wrong (cout is not defined), where (line 2, under the four characters), and how to fix it (the suggested line, with the missing n marked). For the long explanation of any code, run bayan explain BYN2001.

  6. 6

    Fix it

    Apply the suggestion.

    let count = 1
print($"{count}")
    $ bayan run hello.byn
1

    That is the whole loop. Next, read about enums, or browse the programs in tests/cases/run in the repository.

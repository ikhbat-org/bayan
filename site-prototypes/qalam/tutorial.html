Your first Bayan program

Five steps from nothing to a native executable, including one error and its fix. You need a terminal and a few minutes.

  1. Get the compiler

    The v0.1 compiler is built from source. It needs the .NET 10 SDK, and zig on your PATH to turn the generated C into an executable.

    git clone https://github.com/ikhbat-org/bayan
cd bayan
dotnet publish src/Bayan.Cli -c Release -r osx-arm64 -o tmp/publish
./tmp/publish/bayan --version

    Use your own runtime identifier in place of osx-arm64. Then run bayan doctor: it checks the C compiler, zig, git and the build cache, and says how to fix what is missing.

  2. Write hello

    Create hello.byn. Bayan files end in .byn, and newlines end statements, so there is no semicolon.

    print("Salam, world!")

  3. Build it

    bayan build compiles to C, then to a native executable. -o names the result.

    bayan build hello.byn -o hello

    Add --emit-c to see the C that was generated.

  4. Run it

    ./hello
    Salam, world!

    bayan run hello.byn does both steps at once.

  5. Read an error, then fix it

    Save this as width.byn. The second parameter carries the particle until, and the call leaves it out.

    i64 width(i64 start, until i64 end) => end - start

let start: i64 = 2
let end: i64 = 5
print($"{width(end, start)}")
    bayan run width.byn

    The message says what is wrong (an argument without its particle), where (line 5, the highlighted arguments) and how to fix it (add until:). The suggested edit would keep the arguments in the wrong order, though, and the particle belongs on end, the end of the range. Put it there:

    print($"{width(start, until: end)}")
    bayan run width.byn
    3

    That is the loop: write, build, read the message, fix. Next, read how argument particles work, or run bayan explain BYN5005 in your terminal.

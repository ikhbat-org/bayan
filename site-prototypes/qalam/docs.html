Language reference / Parameters and arguments

Parameters and arguments

A parameter says how a function may use a value. A call says in what role each value takes part. Bayan makes both explicit, so a call site reads as a sentence and a swapped pair of arguments is a compile error rather than a bug.

Parameter modifiers

ModifierMeaning
noneRead-only. The compiler passes by value or by reference based on size.
refMutable borrow.
moveOwnership transfer. Required for unique values.
outC# compatibility. Prefer returning T? or a tuple.
inAccepted, redundant. Removed by the formatter.

Argument particles

A closed set of role particles, after the Arabic مِن / إلى / بِ, labels every required parameter after the object.

ParticleRole
noneThe object being acted on
fromSource or start
toDestination or recipient
untilExclusive end
throughInclusive end
atPosition or time
byMeans or replacement
forBeneficiary or purpose
asRole
  • A function has at most one unlabeled parameter, the object (BYN5004). The receiver does not count as the object.
  • Every other required parameter takes a particle (BYN5006), and call sites must write it (BYN5005).
  • The particles are part of the function’s name: copy(from:to:).
  • bool parameters must be passed by name.

Overloading by particle set

Overloads may differ by particle set or by parameter type. The checks run at the declaration, so a call never needs C#-style ambiguity resolution: the labels a call writes select the overload.

tests/cases/run/overloads.byn 
// Overloads differ by particle set; a call picks the one its labels fit.

struct Pos {
    i64 x

    Pos plus(by i64 d) => Pos { x: x + d }
    Pos plus(from i64 a, to i64 b) => Pos { x: x - a + b }
}

i64 shift(i64 x, by i64 d) => x + d
i64 shift(i64 x, from i64 a, to i64 b) => x - a + b

let p = Pos { x: 1 }
print($"{p.plus(by: 2).x} {p.plus(from: 1, to: 9).x}")
print($"{shift(1, by: 2)} {shift(1, from: 2, to: 5)}")
output 
3 9
3 4

When a particle is missing

Write the argument without its particle and the compiler names the particle, points at the argument and shows the fix. A swapped pair of arguments of the same type lands here too, which is why Bayan needs no separate same-type naming rule.

tests/cases/diag/arguments-swapped.byn 
// A swapped pair is a particle mismatch (BYN5005); BYN2307 is retired.
i64 width(i64 start, until i64 end) => end - start

let start: i64 = 2
let end: i64 = 5
print($"{width(end, start)}")
print($"{width(start, until: end)}")

Related

Variadic parameters use rest, and the generated constructor of an @positional struct is exempt from particles. Both are covered in the specification, section 10.

Write a program that answers a question about Bayān's integer arithmetic by printing the answer.

Aisha and Bilal each keep a count of sadaqah coins in a `u8` that holds 250. A third value, the debt, is an `i8` that holds -120.

- Aisha adds 10 to her count with Bayān's wrapping addition.
- Bilal adds 10 to his count with Bayān's saturating addition.
- 10 is taken from the debt with Bayān's wrapping subtraction.

What does each of the three operations give? Compute each with the operator the language provides for it, and print the three results, one per line, in this form:

```
aisha: <result>
bilal: <result>
debt: <result>
```

The program reads no input.

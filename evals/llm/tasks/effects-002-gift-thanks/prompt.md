Write a file that declares one public function for thanking a donor. Do not write a `main` function or any top-level statements.

Declare, as `public`:

```
void thankDonor(string donor, for i64 amount)
```

`thankDonor` prints one line to standard output. The line names the donor and the amount. It returns nothing and reads nothing.

Give the function the `uses` clause its body needs, and no effect beyond it.

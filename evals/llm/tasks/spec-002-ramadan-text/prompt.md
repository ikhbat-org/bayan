Write a program that answers a question about Bayān's strings by printing the answer.

Bilal writes the name of the month of fasting as the string `Ramaḍān`, with a dot under the d and a bar over the a. A string in Bayān is valid UTF-8.

How many bytes does the string hold, and how many Unicode scalar values (letters, as a reader counts them) does it hold? Use the member the language provides for each, and print the two answers, one per line, in this form:

```
month bytes: <number>
month letters: <number>
```

The program reads no input.

Bayān is a value-oriented language that compiles to native code. No runtime, no garbage collector, no exceptions.

Compile your first program Read the docs

A binding says whether it can change

A let binding holds one value while it is in scope. A var binding may be assigned again. The keyword sits at the declaration, so a reader sees which names can change without searching for assignments.

  • Assigning to a let binding is a compile error.
  • A type can follow the name, or come from the value.
  • The compiled program runs on its own, with no runtime beside it.

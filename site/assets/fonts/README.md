# Fonts

These are woff2 files from Fontsource (`https://cdn.jsdelivr.net/fontsource/fonts/<family>@latest/`), stored here so the site loads nothing from outside. All four families are under the SIL Open Font License 1.1; each `<family>-license.txt` holds its license.

| Family | Use | Files |
|---|---|---|
| Inter | UI, headings | 400, 600, 700; latin + latin-ext |
| Alegreya | prose | 400, 400 italic, 700; latin + latin-ext |
| JetBrains Mono | code | 400, 400 italic, 700; latin + latin-ext |
| Amiri | Arabic | 400, 700; arabic |

The latin-ext files carry ā (U+0101) for "bayān".

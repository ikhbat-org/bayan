Clarity is a property of the program.

Bayān is a value-oriented language that compiles to native code. No runtime, no garbage collector, no exceptions.

Read the documentation Download Bayān 0.3.2

Nothing hidden in a binding

A let binding holds one value. A var binding may change. Both are visible at the declaration, so the reader knows what can move.

  • One call starts the program.
  • The type is part of the declaration.
  • The binary runs on its own.

Lists

A list holds values in order. It grows when you add an item and shrinks when you remove one.

Creating a list

The item type is written in angle brackets, as in List<i64>. Call append to add a value; the full example shows the list as it changes.

Visiting every item

A for loop reads each item in order, from the first to the last. The loop body does not need an index.

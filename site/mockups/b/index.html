A small language with the whole program in view.

Bayān is a value-oriented language that compiles to native code. No runtime, no garbage collector, no exceptions.

Read the documentation Download Bayān 0.3.2

The shape of a binding is visible

A let binding holds one value. A var binding may change. Both are written where they are declared, so a reader does not have to look for a later assignment.

  • A declaration names its type.
  • Mutation is named at the declaration.
  • No runtime sits between the source and the binary.

Lists

A list holds values in order. It grows when you add an item and shrinks when you remove one.

Adding and reading values

The type is written in angle brackets, as in List<i64>. Call append to add an item; the full example shows the list as it grows and shrinks.

Visiting every item

A for loop visits each item in order. The loop body reads the item directly, without an index.

A language that keeps the whole program in view.

Bayān is a value-oriented language that compiles to native code. No runtime, no garbage collector, no exceptions.

Read the documentation Download Bayān 0.3.2

Bindings say what can change

A let binding fixes a name to its value. A var binding lets the value change. The keyword sits at the declaration, so the answer is on the page.

  • A program starts with one call.
  • Values keep their type from the first line.
  • Nothing is hidden behind a runtime.

Learn / Collections

Lists

A list holds values in order. It grows when you add an item and shrinks when you remove one.

Adding and reading values

Create a list with a type in angle brackets, such as List<i64>. Call append to add an item; the full example shows the result on screen.

Visiting every item

A for loop visits each item in order, from the first to the last. The loop body can read the item without naming an index.
